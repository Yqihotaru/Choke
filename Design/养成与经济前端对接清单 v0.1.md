# 养成与经济前端对接清单 v0.1

> 用途：给前端重构（Fable 基础上接新交互）提供明确的接口协议、状态机与子界面规格。
> 对应后端实现：`apps/api/src/routes/progression.ts`、`dungeons.ts`、`packs.ts`、`market.ts`。

---

## 1. 卡牌突破（进阶）独立子界面（40 / 50 / 60 / 70 级）

### 1.1 触发时机
- 在卡牌详情页进行**喂养（`POST /users/:userId/cards/:userCardId/feed`）**时，若卡牌到达 `40 / 50 / 60 / 70` 级（非本体卡），后端会在突破节点停下：
  - 普通升级被拦截时返回 `blockedCost > 0`（经验保留在 `card.exp` 中不丢失）；
  - 当 `card.level` 处于 `40 / 50 / 60 / 70` 且 `card.exp >= expToNext(...)` 时，喂养按钮应切换为**「进阶 / 突破」**并打开**独立突破子界面（Modal / Drawer）**。

### 1.2 子界面展示要素
- **当前阶段与下一阶段上限**：`Lv.40 → Lv.50` / `Lv.50 → Lv.60` / `Lv.60 → Lv.70` / `Lv.70 → Lv.80`。
- **消耗清单**：
  - **经验**：`expToNext(level, rarity, isHero)`（提示当前已蓄满 `card.exp`）。
  - **突破金币**（来自 `BREAKTHROUGH_COIN_COST`）：
    - `40 → 41`：`300` 金币
    - `50 → 51`：`500` 金币
    - `60 → 61`：`500` 金币
    - `70 → 71`：`700` 金币
  - **阀门 / 进阶材料槽位**（按 `经济与养成系统 v0.3` §9.2–9.3 预留展示位（这些系统后端还没做）：阀门 `1 / 2 / 4 / 8` + 进阶材料；当前后端材料槽位未接入前先展示“所需金币 + 预留阀门占位”）。
- **操作按钮**：调用 `POST /users/:userId/cards/:userCardId/level`，成功后刷新 `card` 与钱包 `coins`；金币不足时捕获 `400 not_enough_coins` 并高亮缺口。

## 2. 体力溢出槽（720）与体力药水

- **读取体力**：`GET /users/:userId/stamina`
  - 返回 `{ value, max: 360, overflowMax: 720, nextIn, potionUsedToday, potionDailyLimit: 2, potionCost: 100, potionGain: 60 }`。
  - 前端进度条建议拆为两段：`0–360`（6 分钟/点）主条 + `360–720`（12 分钟/点）溢出槽。
- **购买体力药水**：`POST /users/:userId/stamina/potion`
  - **100 金币 → +60 体力**，每日限 2 次，可充入溢出槽（720 封顶）。

## 3. 挂机包每日领取（60 包/天）

- **查询今日额度**：`GET /users/:userId/packs/idle` → `{ dailyLimit: 60, claimedToday, remaining, count }`。
- **领取**：`POST /users/:userId/packs/idle/claim`（可选 `{ count }`，不传默认一键领完剩余全部）。

---

## 4. NPC 批量回收（日限 20 张）

- **查询剩余额度**：`GET /users/:userId/cards/recycle` → `{ dailyLimit: 20, usedToday, remaining }`。
- **提交回收**：`POST /users/:userId/cards/recycle`，body `{ userCardIds: number[] }`。
- **前端预览定价**（`npcRecycleValue` 已在 `@choke/shared/economy` 导出）：
  - 基础价：`C 2 / UC 5 / R 12 / E 30 / L 75 / Mythic 180 / Prismatic 450`；
  - 培养过、有已投入经验的卡，按返还经验每 `1,000` 点额外 `+1` 金币（提示玩家：培养过的卡上市场卖通常更划算）。

---

## 5. 市场挂单（押金、税率、价格带、7 天自动取消）

- **上架**：`POST /users/:userId/market/list`
  - 上架时同时扣除 **2% 上架税（`listTax`，不退）** + **5% 押金（`deposit`，最低 1 金币，防止天价乱挂）**。
  - 若已有历史成交记录，价格必须落在均价 **±40%** 区间内（超出会返回 `400 price_out_of_band`，附带 `avgPrice / minPrice / maxPrice`）。
- **下架 / 7 天过期自动取消 / 成交**：
  - 主动下架（`DELETE /users/:userId/market/listings/:listingId`）或满 7 天自动过期时，**押金全额退还**，**2% 上架税不退**；
  - 成交时扣除 **5% 成交税**，卖家收到 `95% 货款 + 退还押金`。
- **成交历史与参考价**：`GET /market/history?cardId=...` → `{ sales, priceBand }`。

## 6. 本体卡命座（上限 8）与吞噬共鸣

- **查询共鸣**：`GET /users/:userId/resonance` → `{ records, summary }`（`totalBpByAttr`, `countsByAttr`, `totalSlots`）。
- **升命座**：`POST /users/:userId/cards/:userCardId/constellation`
  - 本体卡需传 `{ materialUserCardId }`（只能选未出征锁定的 `mirror` 镜像卡）；
  - 同一 `osuId` 镜像只能吞噬 1 次（重复返回 `409 duplicate_source`）；
  - 前端可用 `@choke/shared/resonance` 的 `resonanceAttributeOf(job, mods)` 提前预览加 `ATK / DEF / SPD / CRIT`（+0.5%，单属性上限 3 次，满 3 次提示“仅升命座、属性已达上限”）。
