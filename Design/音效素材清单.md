# 音效素材清单

CC0 真实样本(Kenney / OpenGameArt / BigSoundBank)已放入 `public/sfx/<音名>/<音名>-<序号>.mp3`,索引见 `public/sfx/manifest.json`,逐文件出处见 `public/sfx/CREDITS.md`。试听:`pnpm dev` 后打开 http://localhost:5207/sfx-audition.html 。

**本轮没有空缺**:所有要求的音名都至少有 2 个变体。但下列几类不是"纯现场录音",请重点听:
- `charge` / `melt-3`:CC0 风铃/钟琴**倒放**得到的上升感(衍生),找不到合格的 CC0 蓄力录音。
- `levelup` / `win` / `lose` / `success`:Kenney 的短乐句(钢鼓、萨克斯、拨弦等采样乐器,非现场录音);上下行方向是用音高追踪分析挑的,务必耳听确认。
- `melt`:找不到真实"熔化能量"录音,用 Kenney Sci-Fi slime 近似。
- `reveal-r/e/l/radiant/prismatic`:翻牌录音 + 风铃/钟琴/钟声叠加,越稀有层数越多。
