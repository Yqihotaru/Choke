# 任务与签到前端对接清单 v0.1

给 fable：任务、签到界面要用到的后端接口。规则都在服务端判定，前端只负责显示和点按钮。全部接口需要登录，且只能操作自己的账号（`:userId` 必须是自己）。

返回格式统一：成功 `{ ok: true, data }`，失败 `{ ok: false, error: { code, message } }`。类型在 `@choke/shared/quests`（`QuestsOverview`、`QuestView`、`ActivityView`、`SignInDayView`）。

## 1. 接口

| 接口 | 作用 |
|---|---|
| `GET /users/:userId/quests` | 总览：全部任务、进度、能否领取、重置时间、活跃度宝箱、签到日历 |
| `POST /users/:userId/quests/:questId/claim` | 领一条任务的奖励（领完会给活跃点，点数到了的宝箱随之解锁） |
| `POST /users/:userId/quests/chests/:period/:at/claim` | 领一个活跃度宝箱；`period` 是 `daily` / `weekly` / `monthly`，`at` 是档位（20 / 40 / 60 / 80 / 100） |
| `POST /users/:userId/quests/claim-all` | 一键全领：先领所有完成了没领的任务，再领所有解锁了没领的宝箱 |
| `POST /users/:userId/sign-in` | 今天签到 |

没有推送：任务做完不会主动通知。需要红点时进入主界面 / 回到页面时拉一次 `GET quests`，看 `data.claimable`（可领的条数，**任务和宝箱合计**）。

## 2. 总览 `QuestsOverview`

- `now`：服务器现在的时间。倒计时用 `resets` 减 `now`，不要用本机时间。
- `resets.daily / weekly / monthly`：三个周期下一次重置的时间（日常每天 4:00，周常周一 4:00，月常每月 1 日 4:00，北京时间）。**成就不重置，没有倒计时。**
- `quests[]`：每条任务
  - `id`、`period`（`daily` / `weekly` / `monthly` / `once`，按它分四个标签页；`once` 是一次性成就）、`name`、`desc`
  - `group`：可选的小标题，目前只有成就用（成长 / 收集 / 养成 / 远征 / 日常），成就页按它分栏
  - `target` / `progress`：进度条
  - `claimable`：完成了还没领 → 显示「领取」按钮
  - `claimed`：已领 → 灰掉打勾
  - `rewards[]`：`{ kind, label, count }`，直接渲染图标和数量（`kind` 是 `coins` / `essence` / `stamina` / `item` / `pack`）
  - `points`：领奖后给的活跃点（成就恒为 0）
- `activity.daily / weekly / monthly`：每个周期一排活跃度宝箱
  - `earned`：当期已经攒到的活跃点（**领了任务才算**，封顶在最大一档）
  - `cap`：最大一档的点数（100），进度条的满格
  - `chests[]`：`{ at, rewards[], claimable, claimed }`。`claimable` = 点数够了还没领 → 「领取」按钮；`claimed` = 已领
- `points.daily / weekly / monthly`：`{ earned, total }`，已领取任务的活跃点合计 / 该周期任务总点数。**旧字段，保留兼容；做进度条请用 `activity`。**
- `claimable`：整体可领条数（任务 + 宝箱），主界面红点。
- `signIn`
  - `monthKey`（`2026-11`）、`today`（本月第几天，每月 1 日 4:00 才算第 1 天）
  - `signedToday`：今天签了没有 → 控制「签到」按钮
  - `signedDays`：本月已签几天
  - `days[]`：本月每一天 `{ day, rewards[], signed, special }`，画签到日历；`special` 是有特别奖励的日子，可以做高亮。**没签的过去日子不能补签**，不要给按钮。

## 3. 领取

- 领单条：成功返回 `{ questId, rewards[] }`。成功后重新拉一次总览，活跃点和宝箱状态都会变。
- 领宝箱：成功返回 `{ period, at, rewards[] }`。
- 一键全领：返回 `{ claimed: [questId...], chests: ["daily-20", ...], rewards[] }`，`rewards` 是任务和宝箱**合并过的总额**（同种道具相加），直接弹一个「获得」面板。`claimed` 和 `chests` 都为空表示没有可领的（不是错误）。
- 签到：返回 `{ day, rewards[] }`。签到会顺带让「完成一次签到」这类日常任务变成可领，成功后重新拉一次总览。
- 领取后金币、道具、卡包数量变了，记得刷新对应的钱包 / 背包显示。

## 4. 错误码

| code | 什么时候 |
|---|---|
| `not_done` | 任务还没完成，或宝箱的活跃点还不够（400） |
| `already_claimed` | 这一周期已经领过（400）；多次点击或多开页面时会遇到，提示后刷新总览即可 |
| `already_signed` | 今天已经签过（400） |
| `not_found` | 没有这个任务 id / 没有这一档宝箱（404） |

## 5. 前端要注意的事

1. 不要自己判断「今天是几号 / 该不该重置」。以 `now`、`resets`、`signIn.today` 为准，4:00 换日的边界在服务端。
2. 页面开着跨过了重置点：倒计时到 0 时重新拉一次总览。
3. **周期结束时没领的奖励不会丢**：已完成的任务和已解锁的宝箱会在下次读取任务时以邮件发到邮箱（标题「任务奖励补发」），未完成的作废。建议在界面上写一行提示：「任务在重置前请及时领取，完成未领的奖励会随邮件补发，未完成的进度会清零」。
4. **成就不会过期**，没领的一直留着；成就页不用显示倒计时。
5. 任务内容（名字、目标、奖励、宝箱档位）全部来自服务端的 `content/quests.json`，不要在前端写死档位数。数值目前是占位，之后会调。
6. 活跃度宝箱按「领任务」攒点：玩家做完任务要先点领取，点数才会涨。做界面时可以把「领取任务」后自动刷新宝箱状态作为默认流程；一键全领会把两步一起做完。
7. 推荐谱面任务见下面第 6 节；通行证还没做，等后端第三步再补接口。

## 6. 每日推荐谱面（osu!）

每天（4:00 换）有 1 张推荐谱面。玩家在 osu! 里打过之后回游戏点「检查」，服务端去 osu! 读他的成绩；通过后日常任务 `daily-osu-beatmap`（事件 `osu-daily-pass`）变成可领，照常走任务领取（奖励、活跃点、宝箱都沿用）。类型在 `@choke/shared/osu-daily`（`OsuDailyView`、`OsuDailyCheckResult`）。

| 接口 | 作用 |
|---|---|
| `GET /users/:userId/osu-daily` | 今天的推荐谱面 |
| `POST /users/:userId/osu-daily/check` | 点「检查」 |

`GET` 返回 `OsuDailyView`：
- `beatmap`：`{ beatmapId, title, url, minAccuracy?, minRank? }`；`url` 是谱面页面链接，做「去 osu! 打」按钮；今天没有推荐谱面（池子空了）时为 `null`，整块隐藏。
- `minAccuracy`（百分数，如 95）和 `minRank`（`D` / `C` / `B` / `A` / `S` / `SS`）**只有谱面设了条件才出现**，出现时在谱面名下面写「准度 ≥ 95%」「评级 ≥ S」。没出现就是不限，只要 Pass 就行（挂 NF 也算）。
- `passed`：今天已经通过。
- `cooldownSeconds`：距离下次能点「检查」还要几秒，按钮做倒计时用；0 表示现在可以。
- `day`、`resetsAt`：今天的日期和下次换谱面的时间（ISO）。

`POST check` 返回：
- `{ passed: true, alreadyPassed }`：通过了（`alreadyPassed` 为 true 表示之前已经通过，没有再去查）。成功后重新拉一次任务总览，任务会变成可领。
- `{ passed: false, reason: "no-score" }`：今天还没找到这张谱面的成绩（或者没 Pass）。提示「还没找到你今天在这张谱面上的成绩，打完后稍等一会儿再检查」。
- `{ passed: false, reason: "not-good-enough", found }`：找到了成绩但没达到条件（准度 / 评级不够，或这条成绩已经用过）。

错误码：

| code | 状态码 | 什么时候 |
|---|---|---|
| `osu_not_linked` | 400 | 玩家是邮箱账号，没有绑定 osu!。提示「需要用 osu! 账号登录才能检查成绩」 |
| `no_osu_daily` | 404 | 今天没有推荐谱面 |
| `cooldown` | 429 | 点得太快；错误里带 `cooldownSeconds` |
| `osu_busy` | 429 | 全服查询太多，稍后再试；带 `cooldownSeconds` |
| `osu_unavailable` | 503 | osu! 暂时连不上，稍后再试（不占冷却） |

注意：成绩的结束时间必须在今天 4:00 之后；只认 osu! standard 模式；同一条成绩只能换一次奖；点「检查」之后有 60 秒冷却，请把冷却显示在按钮上，别让玩家连点。
