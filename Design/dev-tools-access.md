# 开发工具的开放范围

状态：草案。现在所有人都能看到，正式上线前要收紧。

## 现状

「关于」面板（`src/desk/panels/player/AboutPanel.tsx`）的「实验室工具」区把下面几个页面直接列给所有玩家：

| 入口 | 路径 | 用途 |
|---|---|---|
| 卡面实验室 | `/card-lab` | 调卡面版式、特效 |
| 卡牌编辑器 | `/card-editor` | 编辑卡牌数据与技能 |
| 卡池实验室 | `/pool-lab` | 调卡池与概率 |
| 全息参考 | `/holo-lab.html` | 闪卡材质参考页 |
| 音效实验室 | `/sfx-lab` | 试听音效；**只在开发模式（`pnpm dev`）下存在**，生产构建里没有 |

开发阶段这样方便，面板里已标注「开发用」。路由本身没有任何访问限制。

## 上线时的目标

- 只对**指定账户**开放，其余玩家既看不到入口，也打不开页面。
- 只藏入口不够：路由要拦，否则知道地址的人照样能进。
- 这些页面如果会写数据（卡牌编辑器），对应的后端接口也要在服务端校验身份，不能只靠前端隐藏。

## 建议做法

1. 服务端维护白名单：环境变量 `DEV_TOOLS_USER_IDS`（逗号分隔的用户 id），或者用户表加 `role` 字段。优先用环境变量，不需要迁移。
2. `GET /auth/me` 的响应里带一个 `devTools: boolean`，前端据此决定是否显示入口。
3. 前端给这几个路由加守卫：`devTools` 为 false 时跳回桌面。
4. 写数据的接口在服务端用同一份白名单校验。
5. 生产环境默认白名单为空，即所有人都不可用。

## 现在已做的

- 「关于」面板里这几个入口加了「开发用」标记，说明上线前会收紧。
- 没有改路由，也没有改后端。
