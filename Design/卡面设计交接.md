# 卡面设计交接

## 项目

osu! 同人卡牌游戏 Choke! 的玩家卡。2:3 竖版，同一组件在 100 / 140 / 220 / 380 / 560px 下复用。

## 代码位置

| 文件 | 内容 |
|---|---|
| `src/card/CardFace.tsx` | 卡面组件 |
| `src/card/card-face.css` | 全部样式 |
| `src/card/types.ts` | `CardFaceData` |
| `src/card/data.ts` | 七档 Demo 卡 |
| `src/pool/face.ts` | 池卡转卡面 |
| `src/pool/*` | 卡池、稀有度、同步脚本 |

## 预览

```bash
npm run dev
# 380px 单卡
http://localhost:5173/card-lab?solo=4&w=380
# 带布局参考线
http://localhost:5173/card-lab?solo=4&w=560&guides=1
```

`solo` 是 `DEMO_CARDS` 的下标：0 C / 1 UC / 2 R / 3 E / 4 L / 5 Mythic / 6 Prismatic。

## 当前结构

四个分区，从上到下：

```
[header]   深蓝块 + 白色名字卡（LEGENDARY / Lv / 名字 / 国家排名 pp / MOD）
[art]      深色插画 + 多层描边 + 底部命座条
[skills]   三条胶囊（深色外圈 + 白色内条 + 金色 AP）
[foot]     深蓝块（职业圆 / BP / 编号 / 白色品牌缺口）
```

## 设计约束

- 所有内部尺寸用 `cqw`，卡宽 = 100cqw，卡高 = 150cqw
- 字体用 Outfit（`--font-heading`），**不要换衬线**
- 七档稀有度靠三样识别：外框渐变、`--panel` 面板色、`--accent` 强调色
- 色板变量定义在 `.cf`，七档在 `.cf[data-rarity="..."]` 里覆盖
- 组件不要依赖后端，卡面只吃 `CardFaceData`

## 目标视觉（参考图的核心特征）

```
┌─────────────────────────────┐
│ 深蓝头部                     │
│  [金徽章] ┌白卡──────────┐   │
│           │ LEGENDARY Lv │   │
│           │ Mrekk        │   │
│           │ AU #1 pp MOD │   │
│           └──────────────┘   │
├─────────────────────────────┤
│ 多层描边插画                  │
│  深蓝→白→深蓝→金→深蓝         │
│                             │
│ 深蓝命座条 + 白色凹槽 + 星    │
├─────────────────────────────┤
│ 深蓝胶囊 + 白色胶囊 + AP      │
├─────────────────────────────┤
│ 深蓝底部块                   │
│ ⚔ BP: 5,783      ID         │
│    ╭─ Choke! Series ─╮      │
└─────────────────────────────┘
```

关键点：

1. **分区要清楚**：四块之间靠颜色和圆角分开，不是靠线
2. **头部白卡贴边**：白卡应从徽章右侧一直顶到深蓝块的右沿和下沿，只留左侧/左下圆角
3. **插画是多层描边**：不是单线，至少 4 层，层与层之间有色带
4. **命座条是凹槽**：深蓝条上挖一个白色圆角缺口，星星在缺口里
5. **底部是独立块**：品牌条是块底的一个白色缺口，不是横穿的白带

## 已完成

- 七档 `--panel` / `--accent` 色板
- 插画多层 inset 描边 + 内侧渐变线
- 头部合并成深蓝块 + 白卡
- 技能双层胶囊
- 命座条深蓝 + 白色凹槽
- 底部深蓝块 + 品牌标签
- `?guides=1` 布局参考线（红=安全区，蓝=模块，黄=元素，竖线=中心）

## 未解决

| 问题 | 现状 | 期望 |
|---|---|---|
| 头部白卡没贴边 | 四周都有深蓝留白 | 右侧/下沿贴住深蓝块，只留左下圆角 |
| 底部品牌条 | 白色圆角标签，72% 宽 | 更像块底缺口，不要横穿 |
| 命座凹槽形状 | 矩形 + 上圆角 | 两侧有台阶/斜切 |
| 插画占位 | 判定圈 + 滑条 | 真实卡用 `a.ppy.sh/{id}` 头像或 banner |
| 小尺寸 | 100px 下文字隐藏 | 可接受，但白卡/深蓝比例要检查 |

## 验收标准

- 560px 下四块分区一眼能分出来
- 左右留白对称，参考线红框内不溢出
- 100px 下不糊、不爆版
- 七档只看颜色也能区分

## 不要做

- 不要换掉 cqw 体系
- 不要动 `src/pool/` 的稀有度公式和数据同步
- 不要把 `CardFace` 改成依赖网络请求

## 肖像版与 B 侧栏版（卡面实验）

以上为原始交接内容；以下记录本次新增的实验卡面。

### 项目与入口

Choke! 玩家卡，2:3 竖版；所有内部尺寸用 `cqw`，卡宽 = 100cqw。组件只接收 `CardFaceData`，不依赖网络请求或后端状态。

- 游戏里的卡面统一走 `src/card/GameCardFace.tsx`，当前是 B v2 · 大元素（暗色、MOD 在名字后）；换游戏卡面改这个文件，并把 `faceMeta.inGame` 挪到对应版本。肖像渲染器在 `src/card/CardFace.tsx` + `card-face.css`。
- 实验室：`/card-lab`；编辑器：`/card-editor`。
- 实验卡面由 `src/card/faces/index.ts` 自动扫描；每个版本导出 `faceMeta` 和默认组件，约定见 `src/card/faces/README.md`。不要另建手工版本列表。
- 上游原有的当前版、星章版、Paper & Prism、腰封各版继续保留；本次增加肖像版和 B v1／v2。肖像版注册项直接复用 `CardFace.tsx`，避免复制实现。

### 预览与分享

```bash
pnpm dev
# 主游戏肖像版（独立注册为实验版本）
http://localhost:5173/card-lab?style=portrait
# B v1：整体放大前；浅卡纸、头像角 MOD
http://localhost:5173/card-lab?style=b-v1&theme=light&mods=portrait
# B v2：当前大元素版；暗卡纸、侧栏 MOD
http://localhost:5173/card-lab?style=b-v2&theme=dark&mods=spine
# 单卡，DEMO_CARDS 下标 4 = L
http://localhost:5173/card-lab?style=b-v2&solo=4&w=380
```

`mods` 可为 `spine`／`portrait`／`name`。切换版本、主题、MOD 同步 URL，刷新／分享保留。`solo` 为七档 Demo 下标 0–6；单卡支持 `foil=1`、`mode=battle`、`embed=1`。所有版本也会自动出现在编辑器中。

### 肖像版

- 大头像居中；左上稀有度徽记与全名，右上等级和命座，已装 MOD 竖排六边形。
- 自定义 banner 虚化压暗；没有 banner 或属于 osu! 预设背景时，用 `motif.ts` 按卡 ID 确定的三角底纹（`data.ts` 的 `isCustomBanner` 判断）。
- 名字下是国旗、排名、pp；技能固定三行，不足补虚线空槽；底栏为职业、BP、实例序号。
- 稀有度靠整圈色边、烫印和底纹；Mythic 是宝石红工艺（原名 Radiant，现已统一改名，前后端 id 与显示名一致）。
- `.cf` 是主游戏肖像卡；上游保存的当前版使用 `.cfcur`，不会互相覆盖。受光节点在 `light.ts`。

### B 侧栏版

`src/card/CardFaceB.tsx` + `card-face-b.css` 是共用渲染器（`.cfb`）；`faces/b-v1.tsx`、`b-v2.tsx` 只注册两个尺寸版本。暗／浅卡纸、三种 MOD 摆法、稀有度底纹和空技能槽共用结构。

- 侧栏保持 13cqw：顶部黑色半透明稀有度徽记，MOD 可移到头像角或名字后；Lv 和六颗星固定在底部。
- 主区从上到下：banner／世界排名水印 → 头像与排名／pp／BP → 名字 → 三行技能 → 职业／序号。
- Lv 数字两版均为 8.6cqw；空星暗色、普通亮星金色，本体高阶星虹彩。

| 尺寸（cqw） | B v1 · 放大前 | B v2 · 大元素 |
|---|---:|---:|
| 命座星 | 4.6 | 6.2 |
| 顶部徽记 | 9.4 | 11 |
| 侧栏 MOD | 9×8 | 11×10 |
| 名字缩放倍率 | 1.05 | 1.22 |
| 技能行／技能名 | 11.6／5.4 | 14／6.6 |
| 属性圆／AP、MP 圆 | 7.4／7 | 10／9 |
| 排名／pp／BP 数字 | 5／3.8／10 | 6／4.6／11.5 |
| 职业／序号 | 4.2／4.4 | 5／5.2 |

B 战斗态收起侧栏、身份和底栏，保留大头像和技能；闪卡膜与版本、主题共用。

### 数据与验收

- 实例的 `serial` 是该卡被发行的第几张，`pulled` 是累计发行数；图鉴没有实例时不显示序号。交易不改号，熔卡不减发行数。
- 发号、旧库补号及恢复限制见根 README 的数据库说明。桌面卡面快照在登录后按实例 ID 从服务端刷新。
- 检查七档、两主题、两尺寸、三种 MOD 摆法，以及 100px 战斗态／200px 卡册／360px 详情；等级、星、徽记不重叠，技能少时空槽保留。
- 头像和 banner 来自 osu!，远程图片不可达时只能确认布局，不能宣称图片完整视觉验收。
- 不改 `src/pool/` 的稀有度公式、战斗数值或数据同步；不要改掉 Outfit／`cqw` 体系。
