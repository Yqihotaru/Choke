# Choke! 补给箱系统 v0.1（supply）

> 状态：**设计定稿，未实现**（2026-11-28）。取代体力和挂机包。
> 关联：`设计原则与方向 v0.1.md` §5.1、`PP种植园与轻社交系统 v0.1.md`。
> 代码位置（计划）：`content/supply.json`、`apps/api/src/supply.ts`、`apps/api/src/routes/supply.ts`、`src/supply/`；独立模块，不塞进 `quests` 或 `packs`。

---

## 1. 它是什么

- 一组**自动攒的箱子**：离线也攒，不用在线，没有倒计时要守，上线一键领取。
- 取代原来的体力和挂机包。**打图永远不扣东西**，箱子是玩家的“每日消耗品与添头”，不是通关门票。
- 所有人都有，是**保底**；种植园是愿意玩的人的**加成**（见种植园文档 §2.5 的分工）。

## 2. 规则

1. **离线最多累计 72 小时（3 天封顶）**，满了就停。既不让回来的人觉得“3 天没上线亏了”，也不让老玩家靠半年产生天量代差。
2. **箱子随主线进度解锁新类别**：推进一章，桌面上多一个新箱子。这是“有成就感”的来源。
3. **升级封顶在主线第 5 章**（10～15 小时可追平）：
   - 总共只有 **5～6 档**，对应序章和 5 章主线。新人第一周打完主线就满级，和开服半年的老玩家站在同一条线上。
   - **加种类 > 膨胀倍率**：不做“1 级 100 金币、满级 10,000 金币”这种；总产量控制在基础的 **1.0× → 1.5×** 的平缓曲线，重点是按进度解锁不同类别的箱子。
   - **升级不拉开每天的数量差**，只加类别；每个类别的速率对所有人一样，不随玩家等级、账号新老变化。
4. **只产“日常消耗与添头”，不产“赛季唯一荣誉”**：唯一卡面、高难荣誉只靠手打远征和赛季挑战拿到；箱子只负责让新老玩家都舒舒服服有包开、有菜做、有经验拉新卡。
5. 健康提醒（连续玩较久时提示休息）**只提醒，不减产**。
6. 经验池相关资源**不能交易、不能转赠**。

## 3. 箱子类别与解锁

| 解锁时机 | 箱子 | 装什么 | 依赖 |
|---|---|---|---|
| **序章** | 金币 / 走量包箱 | 金币、走量卡包（C / UC / R 为主的普通包） | 无 |
| **第 1～2 章** | 经验餐券箱 | 经验池（累计，可分给任何卡） | 经验池字段与分配界面（**还没做**） |
| **第 3～4 章** | 厨房 / 赌博箱 | 调味料、大转盘碎片 | 种植园料理（调味料）、大转盘（**都还没做**） |
| **第 5 章通关** | 藏品箱 | 外观类、少量收藏向奖励（⏳ 内容待定，见 §6） | 外观素材（**还没有**） |

- 每个类别**独立记账**：各自有“上次领取时间”，解锁那一刻才开始攒（不补发解锁之前的）。
- **一键领取**：一个按钮把所有已解锁箱子一次领完，弹一个合并的“获得”面板。
- 种植园打工卡的小加成（候选，⏳）挂在“基础速率 + 若干加成”里，现在加成项为 0。

## 4. 服务端设计（给以后落地用）

- **内容层**：`content/supply.json`，每种箱子一行：`id`、名字、解锁条件（通关某张主线地图）、每小时速率、封顶小时数、内容列表（金币 / 卡包 / 经验池 / 道具）。加新箱子只改内容，不改代码。
- **数据**：一张 `supply_boxes` 表，`(user_id, kind)` 唯一，存 `last_claim_at`。不用定时任务：
  - 读：`已攒 = min(现在 − last_claim_at, 封顶) × 速率`，向下取整。
  - 领：同事务里先 `lockUser`，算已攒、发放、把 `last_claim_at` 设为现在；重复点、并发点只会发一次。
- **只信服务器时间**，不接受前端时间。
- **解锁判断**：读 `map_clears`（通关记录），不按玩家等级。解锁时 `last_claim_at` 记为解锁那一刻。
- **新号**：完成新手引导后开始攒，不从注册那一刻开始。
- 每种资源都走账本，来源 `supply-box`（`sourceRef` = `箱子 id@领取时间`）。经验池要先有“经验池”字段和账本类型。
- **校验**：`pnpm content:check` 核对卡包、道具、地图是否存在；速率、封顶必须为正；每个类别的总产量要在文档表里登记（见 §5）。
- **测试**：封顶、取整、重复和并发只发一次、解锁前不攒、解锁后从解锁时算起、一键领合并、账本对得上。

## 6. 需要重新确认的冲突

方案里有两处和之前定下的规则对不上，实现前要选：

1. **藏品箱里的“少量精华”**：之前定的是“**精华只来自分解闪卡**”，稀缺性靠这个保住。箱子产精华会破坏它。我建议藏品箱**不产精华**，只放外观类和纪念类奖励。⏳
2. **藏品箱里的“更高档卡包概率”**：箱子只产走量包（C / UC / R 为主），不给高稀有度包；“更高概率”如果指把走量包里 R 的比例略调高，可以；指出 E 以上就不行。⏳

## 7. 落地顺序

1. 先有**经验池**（字段、分给卡的接口和界面），否则经验餐券箱没东西可装；这也是目前卡牌无法升级的缺口。
2. **补给箱模块**（金币 / 走量包箱先上，只有一个“领取”按钮）。
3. 随着序章、第 1～5 章样本配出来，按章节接入后面的箱子。
4. 种植园落地后，再把厨房 / 赌博箱和打工加成接进去。
