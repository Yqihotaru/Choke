## 0. 读法

| 记号 | 含义 |
|---|---|
| **AP** | 行动点消耗。每张卡每回合只能行动 1 次，未用完的 AP 可继承（上限默认 6，出征前花远征点数可升到 10） |
| **倍率** | 相对该卡 ATK / INT 的伤害系数；多段技能写作「N 段，每段 X%」 |
| **费用标签** | 常态 / 累积（每次使用永久 +1 AP）/ 单次（整场 1 次） |
| **疲惫** | **所有主动技能通用**：这张卡上回合用过该技能，本回合 +1 AP，不叠层。不再是标签 |
| **被动** | 常驻生效，不占行动、不消耗 AP；卡被 Down 则失效 |
| **强度** | 侧面支援的强度 1–3（默认 1）；拆除技能的 `breakTier` 不低于支援强度才拆得动 |
| **状态几率** | 附带状态的技能不是必中，基础几率按档位（弱 80% / 中 65% / 强 45%）再乘敌人档位修正 |

> 卡面与战斗**共用同一份技能数据**：卡面印什么名字、几费、什么属性，战斗里就是什么。
> 卡上只存技能 id；认不出的 id 一律报错，没有任何兼容与别名。
> **没有 MP，没有子职业。** 技能直接归四大职业，洗技能就是在同一职业的技能池里重新发。

## 3. 战斗流程要点（与技能交互）

```
我方 Round
  ├─ 回合开始：AP +2（舞者增幅 +1 / 恐惧 −1 / 空转 +1）· DOT 结算 · 掷 Boost/必杀/连击
  ├─ 右侧攻击型支援行动（发动率按各支援自己写的 procRate，没写按 60%；50% 伤害；按支援自带的 combo 值加 Combo）
  ├─ 迅捷卡抢攻（0 AP，70% 伤害，+1 Combo；基础抢攻率 14% × 迅捷技能的 swiftRate）
  ├─ 主队行动（7 张，各自消耗 AP；每张每回合 1 次）
  └─ 回合结束：Combo 清零
敌方 Round
  └─ 按预告意图逐条结算 → 敌方支援追击 → 蓄力 +1 层
```

**几个容易踩的点**

| 机制 | 规则 |
|---|---|
| 疲惫 | 只看「这张卡上一回合是否用过这个技能」。用过 → 本回合 +1 AP；不用 → 恢复原价。**永远只 +1，不叠层**，所有主动技能通用 |
| 远征累积 | 每用过一次，此后永久 +1 AP（封顶到 AP 上限，超过就再也用不出来） |
| 单次 | 整场战斗只能使用 1 次 |
| 硬控打醒 | 眠咒 / 击晕控住后，**任何命中都会立刻解除**——想控就别打，想打就别控 |
| 警觉 | 精英 / BOSS 被硬控后获得 3 回合免疫，且每场最多被硬控 2 次 |
| 状态几率 | 技能附带的状态要过几率：弱 80% / 中 65% / 强 45%（下位技能的强档状态会再打折，如魅惑 35% / 40%），再乘敌人档位（普通 ×1.0 / 精英 ×0.8 / BOSS ×0.65）；硬控另走硬控判定（普通 80% / 精英 65% / BOSS 50%，遇到难以打断的招式 ×0.4） |

| 打断 | 攻击照常结算，之后额外判一次打断：成功率 = 档位基础率 × 稀有度系数，难以打断的招式更难抽中、更难成功；失败不掉 Combo、AP 照付 |
