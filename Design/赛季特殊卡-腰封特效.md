# 赛季特殊卡：腰封激光纹

> 状态：备选方案，不进入默认卡面。留给赛季奖励卡、活动卡或高稀有度闪卡。

## 想法

左侧黑胶腰封不要再只是深色纸带，而是做成「激光微雕 + 棱镜高光」：

- 斜向细纹像刻在腰封上的激光蚀刻
- 高光跟着鼠标纵向游走，像一层很薄的棱镜膜
- 只在闪卡上出现，不改变非闪卡

## 适用位置

优先给 v5.2「暗夜腰封」这一类有独立左侧脊的卡面：

```text
src/lab/faces/night-obi-52.tsx
src/lab/faces/night-obi-52.css
```

类名前缀是 `cfn2`，腰封宽度是 15cqw，和方案里的 `width: 15cqw` 对得上。

## 技术要点

- 在 foil 层里加一个 `<i className="cfn2__foil-obi" />`
- 复用 v5.2 已有的 `--spectrum`、`--at-far`、`--my`
- `mask-composite: intersect`：斜纹 + 跟随鼠标的径向高光
- `mix-blend-mode: screen` 在深色腰封上提亮
- 战斗态隐藏；140px 以下降级或隐藏，避免摩尔纹

## 风险与调参

| 风险 | 处理 |
|---|---|
| 腰封上的品阶/Lv/MOD 被高光洗掉 | `opacity: 0.45–0.55`，必要时只给高稀有度闪卡 |
| 140px 以下斜纹摩尔纹 | 170px 降宽度，140px 去掉斜纹只留径向光，120px 隐藏 |
| 满卡册性能 | 只在 `card.foil` 且高稀有度时挂载 |
| 亮色主题 | 腰封仍是深色，先测 `screen`；太亮可换 `soft-light` |

## 建议的启用规则

```text
普通闪卡：保留现有全卡膜
L / Mythic / Prismatic 闪卡：额外加腰封激光纹
赛季奖励卡：可以强制启用，作为赛季识别
```

这样普通闪卡不会太吵，高稀有度和赛季卡有单独的“值得多看一眼”的理由。
