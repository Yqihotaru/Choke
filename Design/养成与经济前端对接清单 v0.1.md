# 养成与经济前端对接清单 v0.1

> 用途：给前端重构提供接口协议、状态机与子界面规格。数值以代码和 `content/` 为准，规则解释见《经济与养成系统 v0.3》。
> 对应后端实现：`apps/api/src/routes/progression.ts`、`dungeons.ts`、`packs.ts`、`market.ts`。
> 2026-11-25 按现状核对过：所有接口都要求登录用户本人（路径里的 `:userId` 必须是自己）；返回统一是 `{ ok: true, data }` 或 `{ ok: false, error: { code, message, ... } }`。

## 1. 卡牌养成总览：谁能干什么

| 操作 | 接口 | 材料 | 结果 |
|---|---|---|---|
| **喂养**（加经验） | `POST /users/:userId/cards/:userCardId/feed` | 任意卡（本体卡除外）+ 碎片 / 经验乐谱 | 经验折算后自动升级，过突破关自动扣金币 |
| **手动突破一级** | `POST .../level` | 卡里已攒够的经验 + 突破金币 | 升 1 级 |
| **融合**（升命座） | `POST .../constellation` | 一张**同名**卡 | 命座 +1，**留下卡的技能原样保留** |
| **分解** | `POST .../dismantle` | 这张卡本身 | 得 4 个同品质碎片（闪卡另给精华） |
| **镀闪** | `POST .../enhance` | 精华 | 变闪卡 |
| 看可用材料 | `GET .../fuel` | — | 同名重复卡列表 |

共同规则：**本体卡不能当材料、不能分解、不能上架**；**出征中的卡（参战卡锁定）不能被分解、被喂、被融合吃掉、上架**，返回 `in_expedition`。

### 1.1 喂养（`POST .../feed`）

请求：`{ cards: number[], items: [{ itemId, count }] }`，至少选一样；`cards` 最多 60 张且不重复，`items` 最多 20 种。不能喂给自己（`feed_self`）；目标满级返回 `max_level`。

- 一张卡折算的经验 = 该品质的基础喂养值 + 它已投入经验的 75%（`feedExpOf`）。闪卡另外给精华。
- 道具：`items.json` 里碎片（C 10 / UC 20 / R 48 / E 120 / L 288 / Mythic 720 / Prismatic 1920 经验）和经验乐谱（小 200 / 中 1000 / 大 5000）。
- 返回：`{ card, gained, wasted, levelsGained, coinsSpent, blockedCost, coins, essenceGained, essence, items, consumedUserCardIds }`。
  - `wasted`：满级后溢出作废的经验，前端要提示。
  - `blockedCost`：见下节，大于 0 表示卡停在突破关了。
  - `items`：喂完后的道具库存（最新值，直接覆盖本地）。

### 1.2 突破关（40 / 50 / 60 / 70 级，非本体卡）

升过这四级各要花突破金币：`40→41` 300、`50→51` 500、`60→61` 500、`70→71` 700（来自 `BREAKTHROUGH_COIN_COST`，合计 2000）。

- **喂养时自动处理**：经验够了且金币够，就自动扣金币继续升；**金币不够就停在该级**，剩下的经验保留在 `card.exp` 里不丢，返回 `blockedCost`（缺口所需金币）。
- 前端做法：`blockedCost > 0`，或卡处于 40 / 50 / 60 / 70 级且 `card.exp >= expToNext(...)` 时，把喂养按钮换成"突破（花 N 金币）"，点击调用 `POST .../level`（只升 1 级，成功返回 `{ card, spent, coinsSpent, coins }`）。金币不足返回 `400 not_enough_coins`（带 `need`、`coins`），高亮缺口。
- 经验不够返回 `not_enough_exp`（带 `need`、`exp`）；满级返回 `max_level`。
- **没做**：阀门 / 进阶材料（《经济与养成系统 v0.3》§9）。界面上可以先留占位，但后端不会校验也不会扣。

### 1.3 融合（`POST .../constellation`）

- **普通卡**：消耗一张同名卡，命座 +1（上限 6）。不传 body 时自动挑等级最低、没被锁的同名卡；也可以传 `{ materialUserCardId }` 指定。没有同名卡返回 `no_duplicate`；同名卡全在出征里返回 `in_expedition`；满命座返回 `max_constellation`。返回 `{ card, consumedUserCardId }`。
- **本体卡**：命座上限 8，必须传 `{ materialUserCardId }`，且只能是自己的**镜像卡**（`missing_material` / `invalid_material`）；同一个玩家的镜像只能吞噬一次（`409 duplicate_source`）。返回里多 `constellation`、`resonance`、`summary`、`addedResonance`、`capped`。
- 预览共鸣属性：`@choke/shared/resonance` 的 `resonanceAttributeOf(job, mods)`；每次 +0.5%，单属性最多 3 次，满了提示"仅升命座，属性已达上限"（`capped: true`）。
- `GET /users/:userId/resonance` → `{ records, summary }`（`totalBpByAttr`、`countsByAttr`、`totalSlots`）。
- `GET /users/:userId/cards/:userCardId/fuel` → `{ rows }`：除目标卡自己外，所有"同名卡有两张以上"的实例（最多 60 条，按 pp 从高到低），做喂养 / 融合的材料选择列表用。

### 1.4 分解（`POST .../dismantle`）

无 body。除本体卡外任何卡都能分解，包括最后一张。得到 `SHARDS_PER_DISMANTLE`（4）个同品质碎片；升过级的卡另按"已投入经验 × 75%"折成经验乐谱返还（大 / 中 / 小拆分，尾数舍去）；闪卡另给精华。
返回：`{ removedUserCardId, itemsGained, essenceGained, items, essence }`。

### 1.5 镀闪（`POST .../enhance`）

body `{ action: "foil" }`（目前只有这一个）。花 `FOIL_COST` 精华把这张卡变成闪卡。已经是闪卡返回 `already_foil`，精华不够返回 `not_enough_essence`（带 `need`、`essence`）。返回 `{ card, cost, essence, action }`。

### 1.6 道具库存从哪来

`GET /auth/me` 的 `items` 字段，之后每次喂养 / 分解的返回里都带最新的 `items`。

## 2. 体力溢出槽（720）与体力药水

- **读取体力**：`GET /users/:userId/stamina`
  - 返回 `{ value, max: 360, overflowMax: 720, nextIn, potionUsedToday, potionDailyLimit: 2, potionCost: 100, potionGain: 60 }`。
  - 前端进度条建议拆为两段：`0–360`（6 分钟/点）主条 + `360–720`（12 分钟/点）溢出槽。
- **购买体力药水**：`POST /users/:userId/stamina/potion`
  - **100 金币 → +60 体力**，每日限 2 次，可充入溢出槽（720 封顶）。
- **何时扣体力**：只有"拿到东西才扣"；主线和赛季远征不扣体力。副本入口 `POST /users/:userId/dungeons/:dungeonId/run`。

## 3. 挂机包每日领取（60 包/天）

- **查询今日额度**：`GET /users/:userId/packs/idle` → `{ dailyLimit: 60, claimedToday, remaining, count }`。
- **领取**：`POST /users/:userId/packs/idle/claim`（可选 `{ count }`，不传默认一键领完剩余全部）。

## 4. NPC 批量回收（日限 20 张）

- **查询剩余额度**：`GET /users/:userId/cards/recycle` → `{ dailyLimit: 20, usedToday, remaining }`。
- **提交回收**：`POST /users/:userId/cards/recycle`，body `{ userCardIds: number[] }`。
- **前端预览定价**（`npcRecycleValue` 已在 `@choke/shared/economy` 导出）：
  - 基础价：`C 2 / UC 5 / R 12 / E 30 / L 75 / Mythic 180 / Prismatic 450`；
  - 培养过、有已投入经验的卡，按返还经验每 `1,000` 点额外 `+1` 金币（提示玩家：培养过的卡上市场卖通常更划算）。

## 5. 市场（押金、税率、价格带、7 天自动取消）

市场要**完成新手引导，并且账号绑定了 osu!**才能上架和购买，游客和只有邮箱的账号只能看。被拒时返回 `403`，code 为 `feature_locked`，带 `feature`（`market`）、`reason`（`tutorial` 或 `account`）、`level`、`message`（一句话提示，直接展示即可）。旧的 `guest_market` / `market_locked` 已经没有了。其他受限功能（喂养、融合、镀闪、分解、NPC 回收、副本、体力药水、任务、出征）被拒时是同一种格式，`reason` 还可能是 `level`；`GET /users/:userId/progress` 的 `locks` 一次给出所有功能的锁状态，详见《功能解锁表》。

- **看市场**：`GET /market/listings`（全服在架）、`GET /users/:userId/market/listings`（自己的）。
- **上架**：`POST /users/:userId/market/list`，body `{ userCardId, price }`（价格 1 到 `MARKET_MAX_PRICE` 的整数）。
  - 上架时同时扣 **2% 上架税（`listTax`，至少 1，不退）** + **5% 押金（`deposit`，最低 1 金币）**；金币不够返回带 `listTax`、`deposit` 的错误。
  - 若已有历史成交，价格必须落在均价 **±40%** 区间内（超出返回 `400 price_out_of_band`，附带 `avgPrice / minPrice / maxPrice`）；单价上限 `MARKET_MAX_PRICE`。
  - 不能上架：本体卡（`hero_not_tradable`）、卡组里的卡（`in_deck`，先移出）、出征中的卡（`in_expedition`）、已在架的卡（`already_listed`）。
  - 返回 `{ id, price, listTax, deposit, coins, card }`。
- **下架**：`DELETE /users/:userId/market/listings/:listingId` → `{ id, depositRefunded, coins }`；满 7 天未成交也会自动取消。两种情况**押金全额退还**，**上架税不退**。
- **购买**：`POST /users/:userId/market/buy/:listingId`。
  - 扣买家 `price`；成交税 **5%**（`tradeTax`）从卖家货款里扣，卖家收到 `95% 货款 + 退还押金`。卡过户，并从卖家卡组里移除。
  - 错误：`not_found`（已被买走 / 已不存在）、`listing_expired`（超过 7 天）、`own_listing`（不能买自己的）、`not_enough_coins`（带 `need`、`coins`）、`card_moved`。
  - 返回含 `{ coins, price, tradeTax, sellerProceeds, userCardId }`。
- **成交历史与参考价**：`GET /market/history?cardId=...` → `{ sales, priceBand }`。
