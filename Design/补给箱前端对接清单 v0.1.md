# 补给箱前端对接清单 v0.1

> 状态：后端已做好（2026-11-28），前端还没做。设计见 `补给箱系统 v0.1.md`。
> 所有接口都要登录，且只能看和操作自己的（`/users/:userId/...` 里的 userId 必须是自己）。数值现在全是占位，界面别写死。

## 1. 接口

| 接口 | 作用 |
|---|---|
| `GET /users/:userId/supply` | 看补给箱现状 |
| `POST /users/:userId/supply/claim` | 一键领取所有已解锁的箱子 |
| `POST /users/:userId/supply/focus` | 选倾向，body：`{ "focus": "coins" }`；传 `null` 取消倾向 |

三个接口返回的都是同一种 `SupplyView`（领取接口多带一个 `gains`，见下），类型在 `@choke/shared/supply`：

```
{
  boxes: [{
    id, name, summary,
    locked, lockedReason?,        // 没解锁时只显示 lockedReason，不要自己拼"通关某某解锁"
    capHours,                      // 最多攒多少小时（现在是 72）
    hours,                         // 已经攒了多少小时（含已结算的），最多到 capHours
    full,                          // 攒满了
    focus,                         // 当前倾向的资源 id，没选是 null
    focusSharePercent,             // 选了倾向后，倾向资源占多少百分比（现在 70）
    resources: [{ id, kind, label, amount, perDay, sharePercent }]
                                   // amount = 现在能领多少（整数）；perDay = 按当前倾向每天大约多少
  }],
  canClaim,                        // 至少有一样东西能领；false 时按钮置灰
  serverTime,                      // 服务器时间；"已攒多久"以它为准，别用本机时间算
  focus,                           // 当前倾向（同上）
  focusOptions: [{ id, label }]    // 现在能选的倾向，只含已解锁箱子里的资源
}
```

`POST /supply/claim` 返回 `{ gains: [{ boxId, resourceId, kind, label, count }], supply: SupplyView }`：
- `gains` 用来弹合并的"获得"面板。
- 领完后用 `supply` 刷新界面，同时要刷新金币、卡包、经验池（`/auth/me` 里有 `expPool`）。

## 2. 错误码

| code | 什么时候 | 提示建议 |
|---|---|---|
| `nothing_to_claim` | 什么都没攒到（连 1 个整数都不够） | "还没攒到东西，过一会儿再来"，不要当成故障 |
| `bad_focus` | 选了没解锁或不存在的倾向 | 一般不会出现，界面只展示 `focusOptions` |

## 3. 界面要点

- **没有倒计时。** 只显示"已攒 xx 小时 / 最多 72 小时"和每样东西现在能领多少，满了就提示"已满，再攒也不会多"。
- **倾向**是一排按钮（`focusOptions`）加一个"不偏"；改倾向会立刻生效，之前攒的按旧倾向算好，不会变，所以可以放心随时改。
- 每样东西旁边可以显示 `perDay`（每天大约多少）和 `sharePercent`，选倾向时前端能看到变化。
- 没解锁的箱子也列出来，只写 `lockedReason`，灰着。**不要按玩家等级判断**，只信服务端。
- 新号完成引导后才开始攒，引导没完成时 `locked` 是 true，`lockedReason` 是"完成新手引导后解锁"。
- 领取后弹出的"获得"面板用 `gains`；账本里来源显示"补给箱"。
- 经验池不能交易、不能转赠；补给箱出的经验池也一样。

## 4. 现在有什么、之后会加什么

- 现在只有一个箱子：`prologue`（金币 / 走量包箱），资源 `coins`、`normal-pack`。数值是占位。
- 之后按主线进度加箱子（经验餐券箱、厨房 / 赌博箱）、在 `content/supply.json` 里加就行，**前端不用改代码**，遍历 `boxes` 和 `resources` 渲染。
- 资源的 `kind` 目前有 `coins`、`pack`、`expPool`、`item`，前端按 `label` 显示，图标按 `kind` 选，不认识的 `kind` 用通用图标兜底。
