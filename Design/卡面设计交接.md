## 项目

osu! 同人卡牌游戏 Choke! 的玩家卡。2:3 竖版，同一个组件在 100 / 140 / 220 / 380 / 560px 下复用。所有内部尺寸用 `cqw`（卡宽 = 100cqw，卡高 = 150cqw）。组件只吃 `CardFaceData`，不依赖网络请求或后端状态。

## 预览

```bash
pnpm dev
# 当前游戏卡面，380px 单卡（solo 是 DEMO_CARDS 下标：0 C / 1 UC / 2 R / 3 E / 4 L / 5 Mythic / 6 Prismatic）
http://localhost:5173/card-lab?style=b-v3&solo=4&w=380
# 暗 / 浅主题，MOD 摆法
http://localhost:5173/card-lab?style=b-v3&theme=light&mods=name
```

可用参数：`style`（版本 id）、`theme`（`dark` / `light`）、`mods`（`spine` / `portrait` / `name`）、`solo`、`w`（宽度，240–960）、`foil=1`、`embed=1`、`guides=1`（布局参考线，只对 `current` 旧默认版有效）。切换版本、主题、MOD 会同步 URL，刷新和分享都保留。

## 设计约束

- 所有内部尺寸用 `cqw`；字体用 Outfit（`--font-heading`），**不要换衬线**。
- 七档稀有度靠三样识别：外框渐变、`--panel` 面板色、`--accent` 强调色；只看颜色也要能区分。
- 卡面根节点带通用类 `card-face`（外部容器样式、拖拽、受光 `light.ts` 都认它）；闪卡膜用共用的 `CardFoil`，放在根节点最后。
- 组件不要依赖后端，卡面只吃 `CardFaceData`。
- Mythic 是宝石红工艺（原名 Radiant，已统一改名，前后端 id 与显示名一致）。

## B 侧栏版（现用）

`CardFaceB2` 一个渲染器，`version="v1" | "v2"` 切尺寸；游戏版用 `v2`。暗 / 浅卡纸、三种 MOD 摆法、稀有度底纹、空技能槽共用结构。

- 侧栏宽 13cqw：顶部黑色半透明稀有度徽记；MOD 可摆在头像角、侧栏或名字后；Lv 和六颗星固定在底部。
- 主区从上到下：banner / 世界排名水印 → 头像与排名 / pp / BP → 名字 → 三行技能（不足补虚线空槽）→ 职业 / 序号。
- 空星暗色，普通亮星金色，本体卡高阶星虹彩；本体卡有专属徽章。
- 头像或 banner 加载失败时回退到占位，不留破图。
- **100px 小卡**：容器宽度 ≤ 125px 时只隐藏次要文字（水印、pp、序号、被动行）并放大主要数字，不改结构。

## 其他实验版本

留在 `src/lab/faces/`，实验室里归入"历史版本"（默认折叠）：旧默认版（黑卡纸）、星章版、Paper & Prism、黑胶腰封、暗夜腰封 v5.1 / v5.2、肖像版、B v1 / v2。肖像版：大头像居中，banner 虚化压暗，没有 banner 时用 `motif.ts` 按卡 ID 确定的三角底纹。

**战斗态**：早期实验版有"战斗态收起侧栏"（`mode=battle`），现在已经没有了——战斗里直接用游戏卡面，小尺寸靠上面的 100px 容器查询处理。**待确认**：手机端 UI 重构时战斗里的卡面要怎么画（一排小头像 + 血条，见《备忘录》），到时再定要不要重做一个战斗专用的简版。

## 数据与验收

- 实例的 `serial` 是这张卡被发行的第几张，`pulled` 是累计发行数；图鉴没有实例时不显示序号。交易不改号，分解不减发行数。发号与旧库补号见根 README 的数据库说明。桌面卡面快照在登录后按实例 ID 从服务端刷新。
- 验收：七档、两主题、两尺寸、三种 MOD 摆法；100px 战斗里 / 200px 卡册 / 360px 详情；等级、星、徽记不重叠，技能少时空槽保留。
- 头像和 banner 来自 osu!，远程图片不可达时只能确认布局，不能宣称图片完整视觉验收。

## 不要做

- 不要换掉 `cqw` 体系和 Outfit 字体。
- 不要动卡池的稀有度公式与数据同步（`packages/shared/src/pool/`）、战斗数值。
- 不要把卡面改成依赖网络请求。
