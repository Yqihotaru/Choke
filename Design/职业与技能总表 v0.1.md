## 0. 读法

| 记号 | 含义 |
|---|---|
| **AP** | 行动点消耗。每张卡每回合只能行动 1 次，未用完的 AP 可继承（上限 7，高阶部队加成可到 10） |
| **MP** | 法系专属资源，不参与四维预算。每章开始为上限 50%，回合结束回复，**被沉默的回合不回复** |
| **倍率** | 相对该卡 ATK / INT 的伤害系数；多段技能写作「段数 × 单段倍率」 |
| **费用标签** | 常态 / 疲惫（连用 +1 AP，不叠层）/ 累积（每次使用永久 +1 AP）/ 单次（整场 1 次） |
| **被动** | 常驻生效，不占行动、不消耗 AP |

> 卡面与战斗**共用同一份技能数据**：卡面印什么名字、几费、什么属性，战斗里就是什么。
> 卡面上没有的技能，战斗里不会凭空出现；也不再有任何「0 费通用平砍」兜底。

## 4. 战斗流程要点（与技能交互）

```
我方 Round
  ├─ 回合开始：AP +2（舞者 +1 / 恐惧 −1 / 空转 +1）· DOT 结算 · 掷 Boost/必杀/连击
  ├─ 右侧攻击型支援行动（60% 发动率，50% 伤害，每段 +1 Combo）
  ├─ 迅捷卡抢攻（0 AP，70% 伤害，+1 Combo）
  ├─ 主队行动（7 张，各自消耗 AP；每张每回合 1 次）
  └─ 回合结束：Combo 清零
敌方 Round
  └─ 按预告意图逐条结算 → 敌方支援追击 → 蓄力 +1 层
```

**几个容易踩的点**

| 机制 | 规则 |
|---|---|
| 疲惫 | 只看「上一回合是否用过这个技能」。用过 → 本回合 +1 AP；不用 → 恢复原价。**永远只 +1，不叠层** |
| 远征累积 | 每用过一次，此后永久 +1 AP（封顶到 AP 上限，超过就再也用不出来） |
| 单次 | 整场战斗只能使用 1 次 |
| 硬控打醒 | 眠咒 / 击晕控住后，**任何命中都会立刻解除**——想控就别打，想打就别控 |
| 警觉 | 精英 / BOSS 被硬控后获得 3 回合免疫，且每场最多被硬控 2 次 |
| 荆棘 | 逐段固定值反伤（不吃 Combo / 暴击 / 克制），每行动最多反 3 段 |
| 防御 | 点一次 +1 档，作为侧面支援占右侧 1 格；坦克在场 4 档（20/40/70/90%），无坦克 2 档（20/35%）；仅本回合有效 |
| Combo | 1–2 层 0%，3 层 12%，之后线性爬升，10 层封顶 +180%（2.80×） |

## 5. 已知平衡问题（待调参）

当前数值是「机制跑通」用的起点值，没有做过平衡。已知超模点：

| # | 问题 | 说明 |
|---|---|---|
| 1 | **大招倍率整体偏高** | 2.4×–3.4× 叠上 Combo 2.8×、克制 1.25×、必杀 3.0×，单发可达 20 倍以上 |
| 2 | **Combo 曲线太陡** | 10 层 +180% 让「铺场 → 收割」的收益远大于代价 |
| 3 | **支援白送 Combo 起点** | 60% 发动率 × 多支援，每回合自动铺 2–3 层，主队起手就在高 Combo |
| 4 | **0 费技能过多** | 游侠 / 刺客 / 战坦 / 舞者都有 0 费主动，等于每回合多一次行动 |
| 5 | **专拐 + 必杀叠加** | 吟游诗人送 BOOST，配合 3.0× 必杀，单点爆发没有上限约束 |
| 6 | **残血增伤 + 吸血** | 狂战士 25% 增伤与 20% 吸血同时生效，越残越强且打不死 |

> 调参建议顺序：先压倍率 → 再压 Combo 封顶（180% → 140%）→ 再收紧支援发动率 → 最后才动 0 费技能。
