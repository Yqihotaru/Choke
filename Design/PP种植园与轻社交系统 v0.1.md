# Choke! PP 种植园与轻社交系统 v0.1

> 状态：**初版草案**（2026-11-28 整理，内测核心肉鸽远征跑通后排期落地）。
> 定位：**轻量化 QQ 农场 + 赛博盆栽 + 社区整活社交**；替代“按分钟攒的挂机包”与“上班式体力条”，只产添头与社交乐趣资源，不卡远征通关。

---

## 1. 设计原则（防变成苦力）

1. **长周期、不枯萎、低打扰**：作物成熟周期设为 **4～12 小时**（白天种、晚上收，或攒着一起收），永不枯萎，绝不做“10 分钟收一次”的闹钟玩法。
2. **只产“轻资源与乐子”，不绑架 PvE 通关**：产出为金币、通用累计经验池（餐券）、转盘碎片与走量卡包，不产任何必须用来突破关卡的阀门材料。
3. **偷菜保底保护**：单块熟地最多被好友偷走 **20%～25%**，自己大头稳稳保住，偷菜图一乐和留战报吐槽，不伤和气。
4. **不污染高星战斗技能槽**：农场词条独立存在（或只进低星走量卡/单独的生活天赋栏），绝不占用 `L / Mythic / Prismatic` 的战斗技能槽。

## 2.5 离线补给箱（底座，独立模块）

> 补给箱已经拆成独立模块，设计见 `补给箱系统 v0.1.md`（`supply`）。这里只写它和种植园的关系。

- 补给箱是**所有人都有的保底**，种植园是**愿意玩的人的加成**。不种田的人只靠补给箱也不会掉队。
- 补给箱的“厨房 / 赌博箱”（调味料、大转盘碎片）要等种植园的料理和大转盘做出来才有东西可装。
- 打工席（§3.1）可以给补给箱加**一点点**产量，只做小加成，不做“不放卡就少一大截”；是否做、加多少等种植园落地时再定。
- 种植园的产出**不能高到让不种田的人明显落后**。

## 3. 卡片打工、看门斑点狗与“抽鞭子”

### 3.1 派驻席位
- **打工席（2～4 个）**：把抽到的卡（如 `mrekk`、群友镜像卡）放进农田干活。
  - **稀有度 / MOD 联动**：`DT` / `NC` 加速成熟，`HD` 降低被偷概率，`HR` 提升产量但小幅提高“摸鱼/Choke”吐槽率；高稀有度提供稳定基础加成。
- **看门护院 / 斑点狗席（1 个）**：放 1 张卡守门。好友来偷菜时按概率触发抓捕，拦截偷菜并反咬对方一点点金币（上限极低，纯整活）。

### 3.2 农场词条（“基建幻神”设计）
- 不占战斗技能槽，可作为卡片独立附加的 **1 个「生活天赋」**（或仅出现在 `C / UC / R` 走量卡上）：
  - **专业浇水**：缩短所在农田成熟时间 X%
  - **PP 丰收**：收获产量 +X%
  - **超级斑点狗**：作为看门卡时抓偷菜成功率大幅提升
  - **幽灵偷菜（HD）**：去好友农场偷菜时不容易被看门狗发现
  - **摸鱼王**：产量微增，但有概率触发“Choke 了一下”的搞笑日志
- **社交/市场价值**：本来只能碎掉的低星走量卡，因为带极品农场词条而成为“打工皇”，可在市场流通。

### 3.3 拿鞭子抽（每日轻互动）
- 每天有固定几次免费**「督促 / 抽一鞭子」**次数（自己家 + 帮好友加速均可）：
  - 点一下播放清脆音效 + 卡片 Q 弹抖动，直接推进 **10%～15% 成熟度**；
  - 卡片头顶弹出随机 osu! 梗吐槽气泡（如：*“别抽了，手要断了！”* *“刚才那下 Choke 掉 50pp！”* *“再抽我就转战 mania 了！”*）。

## 4. 偷菜与社区留言战报

- 好友列表 / 群友列表 / 在线列表可直接**“去他家逛逛”**。
- **偷菜规则**：只能偷已成熟但尚未收取的田，每块田被偷有保护上限（最多被顺走 25%）；每天偷菜有温和次数上限。
- **动态留言板（核心笑点来源）**：
  - 成功偷到：`【Wuxin】趁【mrekk】打瞌睡，顺走了你 28pp 的 Stream 玉米！`
  - 被斑点狗咬：`【王侯】企图偷走你的高星 PP 树，被看门狗【dusk294】一口咬住，赔了 15 金币！`
  - 帮好友抽鞭子：`【star_tsuki】帮你狠狠抽了【mrekk】一鞭子，成熟度提前了 15%！`
- **“损人”彩蛋：被咬肿手鼠标**：
  - 偷菜被对方的看门斑点狗咬到后，**玩家的鼠标光标会立刻变成一只“被咬肿起来的卡通手”**，并在接下来一段时间内（例如 60 秒～3 分钟，记在本地状态）持续保持肿手造型不消肿，纯粹用来制造群聊截图笑点（纯视觉整活，不影响正常点击）。

## 4.5 远征 × 农场 × 料理 × 市场 / 商店联动（Choke! 宇宙闭环）

- **远征 / 日常掉落**：
  - 掉落**「稀有作物种子」**（回种植园种植，不可直接在商店无限买）；
  - 掉落**「调味料」**（基础调味料产出多，稀有调味料产出少；调味料无法种植，只能靠打本、轮换商店或玩家市场获取）。
- **农场支一个「料理台 / 厨房」（不局限于热汤）**：放入 2～3 种作物与调味料制作各式料理（热汤、便当、甜点、乃至随机炸锅的**黑暗料理**），按食材、火候与掌勺卡影响滚出多段**超长搞笑前缀**（例如：`[mrekk亲手颠勺·加双倍黑胡椒·微焦但能吃·带DT风味的] 特浓 PP 盖饭`）。
  - **掌勺卡「亲密度」与「厨艺熟练度」**：每天种菜/做菜慢节奏积累（每天上线 10 分钟即可，不卡远征主线）；熟练度决定料理能叠出多少个前缀与火候成功率，亲密度解锁专属搞笑台词、专属前缀名与纯外观贴纸。
  - **带进远征吃**：提供下一次远征的轻量开局加护；
  - **挂玩家市场卖**：直接复用现有的玩家市场交易，远征党可花金币向“大厨玩家”买成品料理、稀有种子、作物或调味料；
  - **扔聊天框炫耀**：一键把极品/奇葩超长名字料理卡片发进群聊/游戏聊天框展示。
- **每日 / 每周轮换商店（复用现有后端 `/shop` 接口）**：
  - 商店后端接口仍在仓库中保留，后续直接用于每日/每周轮换上架**基础调味料、少量种子、外观装饰、大转盘筹码**等，用金币购买，既回收溢出金币，又不卖卡关战力。
- **「作物本身」与「稀有种子」的 4 个具体去向（不烂在包里）**：
  1. **料理主料与高阶前缀来源**：普通作物做基础料理；**稀有作物**搭配稀有调味料是解锁特殊流派加护料理、高阶搞笑前缀的必备主料；
  2. **懒人直接一键出货**：不想研究做菜时，收获的作物可直接一键出货换成金币 / 通用经验池 / 转盘碎片；
  3. **市场自然分工**：远征大佬打到稀有种子/调味料卖给农场主 → 农场主种出稀有作物做极品料理 → 卖回给远征大佬；
  4. **图鉴收集荣誉**：集齐作物与奇葩料理图鉴，给纯外观徽章或纪念奖励。

## 5. 美术极简方案（零外包原画也能做得好看）

不用画复杂的 2.5D 大场景或人物 Q 版立绘，直接复用现有资产 + 纯前端视觉：

1. **纯扁平网格布局**：和你们即将做的扁平版 UI 完全统一——左/上方是 4～6 个圆角田块卡（带进度条与成长阶段图标），右/下方是打工席、看门狗席与战报留言板。
2. **卡面即角色**：打工与看门直接复用现有的 `GameCardFace`（缩略版头像/卡框），玩家和群友的 osu! 头像与 banner 本身就是现成、辨识度最高的美术素材。
3. **农作物用极简 SVG 图标**：4 种作物只需 4 个干净的扁平 SVG 图标（麦穗、玉米、辣椒、发光 PP 果树），配合 CSS 生长缩放与微光动画。
4. **“抽鞭子”与“被狗咬”动效**：纯 CSS `@keyframes` 震动/斜线闪光 + 飘字（`+15%` / `-15 金币`）+ 现有音效库里的打击/纸张/金币音效，**0 张额外原画即可上线跑通全部体验**。

## 6. 落地优先级（不打断当前主线）

- **当前阶段（内测前）**：优先跑通 **序章 + 第 1 章远征可玩样本**，验证核心《杀戮尖塔》+《兰斯 10》局内手感。
- **后续阶段（样本跑通后）**：再作为独立模块接入（后端新增农田表 + 偷菜/督促接口，前端新增一个独立面板页），与在线心跳、在线聊天室一起形成完整社交闭环。
- **补给箱（见 `补给箱系统 v0.1.md`）要早于农场**：它取代了体力，经验池和补给箱不做完，玩家现在**没有升级途径**。所以补给箱和经验池先单独落地（只有一个“领取”按钮），种植园面板后来再把它接进去，不用等整个农场。
