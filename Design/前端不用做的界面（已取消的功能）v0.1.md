# 前端不用做的界面（已取消的功能）v0.1

> 2026-11-28。给前端伙伴：下面这些功能**已经决定取消，后端接口和旧界面都已经删除**（分支 `cut-heavy` 已合并到 master），**不用再做界面，也不用再接**。旧文档里还有对应的接口说明，已经加了“已作废”提示，不要照着做。
> 原因和方向见 `设计原则与方向 v0.1.md`。判断标准：每个系统只问“它是在挡着我进内容，还是在给我更多选择？”

## 1. 已取消，不要做界面

| 功能 | 原来的接口 | 备注 |
|---|---|---|
| 体力、体力条 | `GET /users/:userId/stamina` | 进图不扣任何东西；地图列表和准备页不要再画体力、`not_enough_stamina` 的提示 |
| 体力药水 | `POST /users/:userId/stamina/potion` | 商店里也不再卖 |
| 资源副本（练习室、碎片矿脉、精华回廊）和扫荡 | `GET /users/:userId/dungeons`、`POST .../dungeons/:dungeonId/sweep`、`.../run` | 也没有“首通后才能扫荡”的提示 |
| 喂养、经验乐谱、经验道具 | `POST /users/:userId/cards/:userCardId/feed`、`GET .../cards/:userCardId/fuel` | 「强化界面」（目标卡 + 卡/碎片/道具三栏多选）**不做了**，分解卡只给碎片 |
| 挂机包 | `GET /users/:userId/packs/idle`、`POST .../packs/idle/claim` | 心跳和在线状态**保留**（以后给聊天室、在线换卡用），但不再有“按在线分钟领包” |
| 日常、周常、月常任务 | `GET /users/:userId/quests` 里已不再返回 | 任务页只剩**成就**和**签到**，没有周期标签页、没有重置倒计时、没有“过期补发邮件” |
| 活跃度宝箱、活跃点 | `POST /users/:userId/quests/chests/:period/:at/claim` | 任务总览里的 `activity`、`points`、`resets` 字段也没了 |
| 商店里的体力药、经验包、绑定燃料包 | `/shop` | **商店接口保留**，但现在只有碎片类商品；以后给种植园做每日 / 每周轮换商店 |
| 阀门、进阶材料、材料副本 | 从没做过 | **永久不做** |
| MOD（装备型） | 从没做过 | 暂停，如果做只从远征掉落 |
| 突破要碎片 | — | 突破现在**只收金币**，卡详情里不要再显示碎片费用 |

接口返回的类型以 `@choke/shared` 里的为准，改了就不会再有这些字段；前端里已经搜不到体力、副本、挂机、喂养的残留。
