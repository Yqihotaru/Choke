## 1. 它是什么

- 一组**自动攒的箱子**：离线也攒，不用在线，没有倒计时要守，上线一键领取。
- 取代原来的体力和挂机包。**打图永远不扣东西**，箱子是玩家的“每日消耗品与添头”，不是通关门票。
- 所有人都有，是**保底**；种植园是愿意玩的人的**加成**（见种植园文档 §2.5 的分工）。

## 2. 规则

1. **离线最多累计 72 小时（3 天封顶）**，满了就停。既不让回来的人觉得“3 天没上线亏了”，也不让老玩家靠半年产生天量代差。
2. **箱子随主线进度解锁新类别**：推进一章，桌面上多一个新箱子。这是“有成就感”的来源。
3. **升级封顶在主线第 5 章**（10～15 小时可追平）：
   - 总共只有 **5～6 档**，对应序章和 5 章主线。新人第一周打完主线就满级，和开服半年的老玩家站在同一条线上。
   - **加种类 > 膨胀倍率**：不做“1 级 100 金币、满级 10,000 金币”这种；总产量控制在基础的 **1.0× → 1.5×** 的平缓曲线，重点是按进度解锁不同类别的箱子。
   - **升级不拉开每天的数量差**，只加类别；每个类别的速率对所有人一样，不随玩家等级、账号新老变化。
4. **只产基础性物资，不产藏品**：补给箱（挂机）只出金币、走量卡包、经验池、调味料和转盘碎片这类日常消耗品，**不出藏品、外观、精华、高稀有度包**。唯一卡面、高难荣誉只靠手打远征和赛季挑战拿到；箱子只负责让新老玩家都舒舒服服有包开、有菜做、有经验拉新卡。
5. **可以选箱子的倾向**（见 §3.1）：玩家决定这几天的箱子更偏哪种资源，给每一种资源多开一个入口，上线就有事可干。
6. 健康提醒（连续玩较久时提示休息）**只提醒，不减产**。
7. 经验池相关资源**不能交易、不能转赠**。

## 3. 箱子类别与解锁

| 解锁时机 | 箱子 | 装什么 | 依赖 |
|---|---|---|---|
| **序章** | 金币 / 走量包箱 | 金币、走量卡包（C / UC / R 为主的普通包） | 无 |
| **第 1～2 章** | 经验餐券箱 | 经验池（累计，可分给任何卡） | 经验池字段与分配界面（**还没做**） |
| **第 3～4 章** | 厨房 / 赌博箱 | 调味料、大转盘碎片 | 种植园料理（调味料）、大转盘（**都还没做**） |
| **第 5 章通关** | （不新增类别） | 达到满档，总产量到基础的约 1.5 倍 | 无 |

- 每个类别**独立记账**：各自有“上次领取时间”，解锁那一刻才开始攒（不补发解锁之前的）。
- **一键领取**：一个按钮把所有已解锁箱子一次领完，弹一个合并的“获得”面板。
### 3.1 倾向（选择箱子偏向什么）

- 玩家可以随时选一个**倾向**：金币、卡包、经验、（解锁后）调味料和转盘碎片。选了哪种，这段时间箱子就**多出哪种，少出别的**。
- **总价值不变**：任何倾向下，一箱按“折算价”算出的总价值都一样，只是换着装。不能靠选倾向多拿东西。折算价是内容数据，改数值时一并给你看对照表。⏳
- **只偏不全押**（建议）：倾向给的是“偏重”，其他资源仍然保底少量，避免有人全押金币把经济搞歪，也避免经验池全押后别的断供。偏多少待定。⏳
- **改倾向不能套利**：改倾向的瞬间，先把已攒的时间按**旧倾向**结算成存货，再从现在起按新倾向攒；不能“攒满了、领之前改成最贵的”。存货和已攒时间合起来受 72 小时封顶约束。
- **折算要保守**：金币能在市场流通，所以金币的折算价偏低，倾向全偏金币也不会推高通胀；经验池不能流通，折算价按“省了多少刷图时间”定。⏳
- 倾向只在**已解锁的类别**之间选；刚开始只有金币和卡包两种，选择感随章节增加。
- 数据：`supply_prefs` 存玩家当前倾向和“已结算存货”（按资源分），读的时候和 §4 的已攒合并显示。

- 种植园打工卡的小加成（候选，⏳）挂在“基础速率 + 若干加成”里，现在加成项为 0。

## 4. 服务端设计（给以后落地用）

- **内容层**：`content/supply.json`，每种箱子一行：`id`、名字、解锁条件（通关某张主线地图）、每小时速率、封顶小时数、内容列表（金币 / 卡包 / 经验池 / 道具）。加新箱子只改内容，不改代码。
- **数据**：一张 `supply_boxes` 表，`(user_id, kind)` 唯一，存 `last_claim_at`、当前倾向和已结算存货（见 §3.1）。不用定时任务：
  - 读：`已攒 = min(现在 − last_claim_at, 封顶) × 速率`，向下取整。
  - 领：同事务里先 `lockUser`，算已攒、发放、把 `last_claim_at` 设为现在；重复点、并发点只会发一次。
- **只信服务器时间**，不接受前端时间。
- **解锁判断**：读 `map_clears`（通关记录），不按玩家等级。解锁时 `last_claim_at` 记为解锁那一刻。
- **新号**：完成新手引导后开始攒，不从注册那一刻开始。
- 每种资源都走账本，来源 `supply-box`（`sourceRef` = `箱子 id@领取时间`）。经验池要先有“经验池”字段和账本类型。
- **校验**：`pnpm content:check` 核对卡包、道具、地图是否存在；速率、封顶必须为正；每个类别的总产量要在文档表里登记（见 §5）。
- **测试**：封顶、取整、重复和并发只发一次、解锁前不攒、解锁后从解锁时算起、一键领合并、账本对得上。

## 4.1 实际落地和设计的差别

- 倾向是**全局的一个资源 id**（所有箱子共用），存在 `supply_prefs`；每个箱子的存档在 `supply_boxes`（`accrued_from` 从什么时候开始攒、`stock` 已结算的存货、`stock_hours` 存货折算的小时数）。
- 每个箱子自己写 `capHours`（封顶小时）、`valuePerHour`（每小时的总价值）、`focusShare`（选倾向后倾向资源占多少）、`resources`（每个资源的折算价 `worth` 和原占比 `share`）。**同一个资源 id 在不同箱子里折算价必须一样**，校验会拦。
- 一个资源的每小时产出 = `valuePerHour × 占比 ÷ 折算价`。改倾向后，倾向占 `focusShare`%，其余按原占比分剩下的，总价值不变。
- 领取只发整数，小数留在存货里，下次接着攒，不丢；改倾向、取消倾向都先结算。
- 内容校验：卡包必须存在、不是活动包、L 及以上三档合计不超过 2%；地图必须是主线地图；倾向占比必须比每个资源的原占比都大。
- 完成新手引导前不攒；第一次有人看或领的时候才开始计时（所以引导刚完成就去看一眼，才算起点）。要从"引导完成那一刻"算起，得在引导完成时建存档，目前没接。
- 经验餐券箱、厨房 / 赌博箱都还没配进 `content/supply.json`；经验池箱的资源种类（`expPool`）和发放已经支持。

## 5. 数值（全部待定，不要凭空填）

> 等序章和第 1 章样本配好、你亲自打一遍之后，再按“一个正常玩家一天能拿多少”反推。改数值之前，先给“现在值 / 新值”对照表确认。

## 6. 已解决

- 原来想放进“藏品箱”的少量精华、更高档卡包概率，**一概取消**：补给箱不产藏品、精华和高稀有度包。精华仍然只来自分解闪卡。
- 外观、纪念类奖励将来如果要做，走**赛季和成就**，不走补给箱。

## 7. 落地顺序

1. 先有**经验池**（字段、分给卡的接口和界面），否则经验餐券箱没东西可装；这也是目前卡牌无法升级的缺口。
2. **补给箱模块**（金币 / 走量包箱先上，一个“领取”按钮加倾向选择）。
3. 随着序章、第 1～5 章样本配出来，按章节接入后面的箱子。
4. 种植园落地后，再把厨房 / 赌博箱和打工加成接进去。
