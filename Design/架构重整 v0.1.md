# Choke! 架构重整 v0.1

> 状态：进行中。本文记录目标结构、依赖规则与分阶段进度，作为后续拆分的唯一依据。
> 基线：`master` @ 2026-11-19。

---

## 1. 目标结构

```
apps/
  web/        玩家端（现在的 src/，Vite 根）
  lab/        卡面实验室 / 卡池实验室 / 全息参考（不进主包）
  api/        Fastify + PGlite
packages/
  shared/     类型 + 配置 + 纯规则（前后端共用，零 React）
```

**依赖方向（单向，不可逆）**

```
apps/web ─┐
apps/lab ─┼─> packages/shared
apps/api ─┘
```

三条硬规则：

1. `packages/shared` 不出现 React / DOM / window / fetch。
2. `apps/api` 不允许出现 `../../../../src/...`。
3. `apps/lab` 可以 import `apps/web`，反之禁止。

## 3. 下一阶段要点

### 阶段 1：packages/shared

先搬三类东西，其它一律不动：

```
packages/shared/
  types/      Rarity / Element / Job / CardFaceData / CardSkill / Mod
  config/     RARITIES、卡池 id、DECK_SIZE、MARKET_UNLOCK_LEVEL、PACK_SIZE
  skills/     技能注册表（阶段 3 一起搬）
```

过渡手法：`src/card/types.ts` 等旧文件改成 `export * from "@choke/shared/types"`，避免一次性改几百处 import。

### 阶段 3：skillId

```ts
// 卡（数据库）只存引用
skills: [{ skillId: "ranger_volley", level: 3 }, { skillId: "ranger_swift" }]
```

迁移步骤：

1. `cards` 增加 `skill_refs jsonb`（走 migration）。
2. 一次性脚本把老 `skills[].name` 通过别名表翻译成 `skillId`。
3. `toFace()` 优先读 `skill_refs`，读不到回落旧字段。
4. 稳定后删除旧字段。

### 阶段 5：fetch 收口

17 处裸 `fetch` 全部改为 `api.ts` 方法，按域分组：

```
auth.login / auth.logout / auth.me / auth.onboard / auth.tutorialPack
cards.stats / cards.countries / cards.detail / cards.codex
packs.inventory / packs.take / packs.return / packs.open
deck.get / deck.save
progress.get / progress.put
```
