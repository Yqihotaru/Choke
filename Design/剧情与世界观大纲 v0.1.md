# Choke! 剧情、世界观与长地图设计大纲 v0.1

> 状态：初稿草案（纯设计稿，未改任何代码或现有 JSON）。
> 定位拍板：**Choke! 不是“打手牌的卡牌游戏”，而是一款「用 osu! 玩家卡组队的轻度 JRPG 图池远征 + 集换收集游戏」**。
> 调性：**轻松、王道热血、满是 osu! 社区梗的「中二脑补滤镜」喜剧**——彻底告别兰斯 10“四国着火、不救就灭世”的焦躁感，讲一个**“从鼠标萌新被群友 MP 暴打，一路组队打图池，中间省略十万字，最终在 OWC 总决赛把 mrekk 踩在脚下”**的故事。

## 一、核心世界观桥接：怎么把「打 osu! 谱面」和「打 JRPG 魔物」自然融在一起？

### 1. 一句话前提（「中二滤镜」法则）
在现实里，你只是在打 osu!、逛 MP 房、刷 PP、打图池、打 OWC。
但在主角（玩家本人）的**中二脑补滤镜**里，每一次谱面里的噩梦配置（漏滑条尾、偏拍 50、AR8 低速读图、280 BPM 死串、99.8% 最后三圈手抖）都具象化成了挡路的**「失拍魔物」**；而你抽到的 osu! 玩家卡，就是你拉进战队里一起开黑的**「谱面投影队友」**。

> **为什么这个设定能彻底消除割裂感？**
> - 群友不会再问“为什么打音游在砍史莱姆”——因为敌人本身就是**各种臭名昭著的谱面配置与 Choke 心魔**。
> - 也不用强行写沉重的奇幻编年史：既可以一本正经地用 JRPG 史诗腔放狠话，下一秒又能无缝切回“数位板驱动崩了”“群友语音毒奶”的音游吐槽，反差感极强。

### 2. 现有系统 ↔ osu! 赛场语境映射表

| 现有系统 | osu! 世界观里的身份 | 玩家体感 |
|---|---|---|
| **4～7 槽上场组队** | **OWC 4v4 首发 + 替补大名单** | 本来就是组战队，不是打炉石手牌 |
| **本体卡 + 吞镜像卡共鸣** | 你自己的 osu! 账号 + 在 MP 房跟群友/大佬切磋偷师 | 越打越强、吸收各路打法 |
| **卡牌 MOD（DT/HR/HD/EZ…）** | 选手的专精方向（DT 速度怪 / HR 准度怪 / HD 读图怪） | 天然对应战前针对图池选人 |
| **40～50 节点长远征地图** | 一整段**章节征程 / 赛季赛程表 / Mappool 闯关** | 1～2 小时 JRPG 续航探索，24h 自动存档可分次打 |
| **地图分叉路径** | **选图 / Pick & Ban 分叉**（左路 DT 高速线 vs 右路 Tech 技术线） | 走哪条路直接决定遇什么属性的怪与收益 |
| **跨场不回血（队伍血条）** | **全队心态值 / 手感体力条**（小怪掉 5~10%，精英掉 20~40%） | 打连战手酸、心态渐薄，必须算好续航 |
| **篝火 / 休息节点** | **中场暂停 / 擦手汗 / 换笔尖 / 喝口水** | 长地图里的关键喘息点 |
| **弱点破盾（Break）** | **摸透谱面节奏、抓到 Kiai 破绽、打出完美连击窗口** | 破盾挂脆弱 → 一波爆发灌死 |
| **碎片 + 逢 5 洗技能** | **赛前特训 / 针对图池临时加练技能** | 把喜欢的选手卡调教成对应流派核心 |

## 二、40～50 节点章节 / 赛季大地图设计模板

针对**“40～50 节点才撑得起一个章节或赛季非完美线路（1～2 小时沉浸 + 凹关）”**的目标，大地图不靠无脑堆怪，而是按 **「12 个关键节点 + 30～35 个推进节点」** 组装成 4 个大区段：

### 1. 节点配比参考（以 45 节点标准章节图为例）

| 节点类型 | 数量 | 定位与掉血/资源目标 |
|---|---:|---|
| **起点 & 章节终局 BOSS** | 2 | 开场剧情导入 + 终局厚血 BOSS（`conductor` / 章节守关王） |
| **阶段精英 / 小关底（关键节点）** | 4～5 | 每推进 8～10 步设 1 个守门精英（掉血 20%～40%），检验当前血线与 Build |
| **大分支路口（关键节点）** | 3 | 提供风格迥异的 2 条路线（如「高速 DT 线」vs「稳健 NM/技术线」；以及**非完美稳妥线 vs 完美高风险线**） |
| **篝火 / 补给站（关键节点）** | 3～4 | 卡在精英战后或 BOSS 前，提供「回血 / 强化 / 避险」二选一，形成续航呼吸感 |
| **常规谱面战（推进节点）** | 16～18 | 杂鱼组合（单场掉血 5%～10%），持续磨损血线并掉落章节资源 |
| **osu! 梗随机事件（推进节点）** | 10～12 | 30～50 字带选项事件，用血量/金币/路线换高收益或奇遇，打破纯打怪疲劳 |
| **宝箱 / 捷径 / 隐秘点（推进节点）** | 4～6 | 奖励走高风险分支的玩家（如「完美路线」才能摸到的额外宝箱与隐藏剧情） |
| **合计** | **42～50** | **单次打完约 45～90 分钟（高难/凹关可达 2 小时），支持 24h 自动存档分次打完** |

### 2. 四区段推进节奏（让长图有起伏、不枯燥）

```text
[起点]
  └─ 第 1 区段·热身试探（约 10 步）：杂鱼×4 + 梗事件×3 + 小宝箱×1 → 【关键①：1段精英 + 篝火】
       └─ 【关键②：大分支 A（高速爆发线 vs 稳健常规线）】
  └─ 第 2 区段·图池试炼（约 12 步）：按所选分支遭遇对应属性怪×5 + 梗事件×4 → 【关键③：2段小BOSS + 篝火】
       └─ 【关键④：大分支 B（非完美安全线 vs 完美高危线：多1精英+隐藏宝箱）】
  └─ 第 3 区段·心态高压（约 12 步）：高压杂鱼×5 + 强精英×1 + 梗事件×3 → 【关键⑤：终局前篝火/最终整备】
  └─ 第 4 区段·决胜局（约 4～6 步）：门神精英×1 + 战前剧情节点 → 【关键⑥：章节终局 BOSS】
```

> **设计降本技巧**：不需要为每张 45 节点地图做 45 种新怪！只需确定本章的**“主题属性池 + 2 个精英门神 + 1 个守关 BOSS + 3 个专属剧情事件”**，其余推进节点从通用谱面怪池与 osu! 梗事件池里按区段权重拼装即可。

## 四、5 章主线大纲（王道热血吐槽线）

> **写法原则**：每章只在「开场 / 中继分叉 / BOSS 战前 / 通关」放 3～6 句高浓度吐槽对话，**绝不写臭长水字数剧本**；想看故事的笑出声，只想刷图的 3 秒点完。

### 序章 · 鼠标萌新与神秘 MP 房（教学短图）
- **剧情**：你刚装好 osu!，拿着办公鼠标在 2 星图疯狂 Miss，被群友拉进 1 号 MP 房惨遭 6 位数暴打。绝望之际，你的账号觉醒为**本体卡**——系统一本正经地宣布：“检测到强烈的不甘心，已为你开启 OWC 夺冠征程！”
- **教学目标**：开新手包 → 组 4 人小队 → 打完 `tutorial-ghost`，学会放技能与防御。

### 第 1 章 · 农场与手汗的试炼（约 40 节点）
- **剧情**：为了在 MP 房找回场子，你一头扎进“农场与基础功试炼场”。一路见识了漏尾滑条、偏拍噪点和无脑 1-2 大跳，还在路边第一次撞见神秘的 **727** 传说。
- **核心分支**：左路「农图狂冲线（怪脆但爆发高）」vs 右路「基本功打磨线（稳健掉血少）」。
- **守关 BOSS**：`colossus-metronome`（巨像节拍器）——逼你第一次理解“看准破绽回合 + 破盾爆发”。

### 第 2 章 · 变速迷雾与社区淘金（约 45 节点）
- **剧情**：脱离萌新期后，你发现单靠 4 张低星卡已经打不过进阶图池，开始在社区市场淘卡、凑 60 级过渡队、甚至靠“逢 5 洗技能”调教出一套像样的流派。群友吐槽：“你这是打算直接去打地区赛吗？”
- **核心分支**：左路「连击竞速线」vs 右路「异常消耗线」。
- **守关 BOSS**：`tempo-eclipse`（蚀拍日蚀）——双阶段变速考验。

### 第 3 章 · Mappool 地狱（约 45 节点）
- **剧情**：正式组起 5～7 人战队挑战地区赛图池！你发现图池里全是魔鬼：一边是冰冷卡手的低 AR 读图地狱，一边是反直觉的毒瘤技术滑条图。队里光靠平刀已经刮不动了，必须针对弱点与机制配队。
- **核心分支（大双线）**：上路「AR8+HD 冰川线（守门 `glacier-requiem`）」vs 下路「Tech 荆棘线（守门 `thorn-matriarch`）」（非完美线路只需打通其一即可进关底；完美线路可双线制霸拿满隐藏宝箱）。

### 第 4 章 · 资格赛与 Choke 心魔（约 50 节点）
- **剧情**：*（开场官方吐槽过场：「——中间省略十万字枯燥的刷图、换轴、摔数位板与群内互喷日常——」）* 转眼你已经带着 70～80 级主力战队杀进 OWC 资格赛与淘汰赛！此时挡在面前的不再是普通谱面，而是连续 280 BPM 死串与临门一脚断连的终极心魔。
- **守关 BOSS**：前哨 `storm-maestro`（雷鸣首席）→ 终局 `conductor`（失拍指挥·终曲，Tiebreaker 6 分钟决战）。

### 第 5 章（终章）· OWC Grand Finals：把世界第一踩在脚下（预留大关 / 赛季终极挑战）
- **剧情**：聚光灯亮起，直播间弹幕刷屏。对面坐着那个把全世界按在地上摩擦的男人（世界第一大魔王 / mrekk 幻影）。比分来到 6:6 Tiebreaker，全队 7 槽 10 AP 全力出击——这一次，99.8% 最后三个圈，**绝不 Choke！**
- **通关演出**：高举 OWC 冠军奖杯，群友在语音里集体破防喊爸爸，解锁「无尽赛季图池 / 高难度凹分模式」。

## 五、10 条「梗与机制绑定」的 osu! 远征随机事件草案

> 每条事件控制在 30～50 字，**选项直接操作血量 / 金币 / 物品 / 路线**，玩家为了做取舍自然会读完每一句梗。

1. **「语音里群友突然毒奶」**
   - 文案：连击刚过 1,000，耳机里突然传来群友一声“稳了！你这把必 FC！”
   - 选项 A（立刻闭麦硬扛）：全队心态（血量）`-12%`，获得 `200 金币`（顶住毒奶的赏金）。
   - 选项 B（开麦回喷一句）：血量不变，但本节点无额外奖励。
2. **「数位板驱动突然崩溃」**
   - 文案：光标瞬间瞬移到屏幕左上角，数位板指示灯开始诡异闪烁。
   - 选项 A（重启驱动抢修）：花费 `80 金币` 或掉 `8%` 血，获得 `exp-medium ×2`。
   - 选项 B（切鼠标硬打完）：全队血量 `-15%`，但获得 `shard-E ×4`（鼠标战士的尊严）。
3. **「727 · WYSI」**
   - 文案：计分板右下角赫然定格在 **727**，空气突然安静了三秒。
   - 选项 A（大喊一句 WYSI！）：50% 概率全队回血 `+20%` 并得 `150 金币`；50% 概率笑到手抖掉血 `-10%`。
   - 选项 B（装作没看见走过去）：稳稳回血 `+5%`。
4. **「笔尖磨平了」**
   - 文案：笔尖已经磨成斜角，在板子上划出刺耳的摩擦声。
   - 选项 A（换一根新笔尖）：花费 `60 金币`，全队回血 `+25%`。
