# Choke! 技能定义指南 v0.1

> 状态：**字段与规则已落地，定价部分仍是参考**。写新技能、改技能数值之前先读这篇。
> 字段与校验规则以代码为准（`packages/shared/src/skills.ts` 的 `SkillDef`、`skill-check.ts` 的校验）；本文是它们的说明书，外加"该定多少钱"的参考。
> 规则见 `卡牌数值与战斗机制 v0.1.md`，全部现有技能清单见 `职业与技能总表 v0.1.md`（由数据自动生成，共 186 个，名字和数值以它为准）。
> 本文里标 **〔待审〕** 的是建议值，不是现状；没标的是从现有技能里量出来的现状。

## 1. 基本约定

| 约定 | 说明 |
|---|---|
| 技能归大职业 | 每个技能有一个 `job`（坦克、战士、法师、辅助），技能池按它划分。**没有子职业** |
| id 不改 | 技能 id 是卡上唯一存的东西，一旦发出去就不能改；名字可以改。改名后在 §9 的登记表里记一笔 |
| id 格式 | `<前缀>_<动词>`，正则 `^[a-z]+_[a-z0-9_]+$`。前缀只是命名习惯（沿用 bulwark、ranger 等），**不代表任何子职业**，归属看 `job`。下位技能在原 id 后加 `_low`（初阶）或 `_mid`（次阶） |
| 名字 | 不超过 8 个字，全表不能重名；不用别的游戏里的角色名或技能名 |
| 认不出的 id | 导入、发牌、战斗里一律报错，没有别名、没有兜底 |
| 描述 | 默认由字段自动生成（`describeSkill`）；写了 `desc` 就用手写的，带 `statusChance` 时末尾自动补"· 状态几率 X%" |
| 疲惫 | **所有主动技能通用**：这张卡上回合用过该技能，本回合 +1 AP，不叠层。技能里不写疲惫 |
| 没有 MP | 行动成本只有 AP |
| 技能数据放在代码里 | 技能表留在 `skills.ts`，不搬进 `content/`（战斗内容、地图、事件才在 `content/`） |

加一个技能的步骤：

1. 在 `skills.ts` 里写定义。
2. `pnpm docs:skills` 重新生成总表。
3. `pnpm test`（会检查技能表合法、总表没过期、战斗基准没被意外改变）。
4. 如果是有意改了战斗数值：`pnpm --filter @choke/api exec tsx scripts/test-battle.ts --update`，并把新基准随内容一起提交。

## 2. 字段说明

### 2.1 通用字段

| 字段 | 类型 / 范围 | 说明 |
|---|---|---|
| `id` | 字符串 | 见 §1 |
| `name` | 1–8 字 | |
| `job` | `tank` / `warrior` / `mage` / `support` | 技能池归属 |
| `element` | 九属性之一（含物理） | 属性挂在技能上，决定克制 |
| `ap` | 整数 0–5 | 被动必须是 0 |
| `kind` | 见 §2.2 | 技能种类 |
| `costTag` | `normal`（默认）/ `accumulate` / `once` | 费用标签 |
| `once` | 布尔 | 整场限用 1 次；与 `accumulate` 冲突 |
| `target` | `enemy` / `self` / `ally` / `team` | |
| `unlockTurn` | 整数 2–10 | 第 N 回合起才能用（目前只有无偿之舞，第 4 回合） |
| `scaleStat` | `atk` / `int` | 伤害吃哪个面板。不写则按职业默认（战士、坦克吃 ATK；法师、辅助看属性，物理吃 ATK，其余吃 INT）。只管"用谁的攻击力"，敌人那边的减伤仍按属性算。目前没有技能用 |
| `desc` | 字符串 | 手写描述（覆盖自动生成）。不写 AP，消耗由界面单独显示 |
| `effects` | `{ name, description }[]` | 需要单独列出的效果（如召唤物、增益档位）；战斗提示逐条渲染成「【name】：description」，不影响 `desc` |
| `minRarity` | 稀有度 | 最低发放稀有度，默认 C；发牌只在 `minRarity` 到 `maxRarity` 范围内的卡上抽到它 |
| `maxRarity` | 稀有度 | 最高发放稀有度，默认 Prismatic（不设上限）；用于"下位技能不发给高品质卡"；`minRarity` 不能高于它 |

### 2.2 kind 与必填字段

| kind | 必填 | 说明 |
|---|---|---|
| `damage` | `power`、`hits` | 伤害 |
| `interrupt` | `power`、`hits` | 伤害 + 额外一次打断判定（每回合限 1 次） |
| `heal` | `healPct` | 回复队伍，占队伍最大生命的比例（不随卡牌等级变，单次不超过 0.15）；不写 `power`；可带 `cleanse`、`revive` |
| `guard` | `power` | 护盾 |
| `taunt` | `selfStatus` | 嘲讽并给自己上状态 |
| `buff` | `stat`、`amount`、`turns` | 全队属性增益；可带 `boostAllies`、`comboBoostAllies` |
| `debuff` | `statusId` | 减益，可带伤害与拆除 |
| `control` | `statusId` | 硬控（眠咒、击晕），不写 `statusChance` |
| `ap` | `amount` | 给 AP |
| `summon` | `supportDef` | 在侧面支援栏放一个支援 |
| `passive` | `passive: true` + 至少一个被动效果字段 | 被动；`ap` 为 0，不能带主动字段 |

### 2.3 伤害、状态、斩杀、拆除

| 字段 | 范围 | 说明 |
|---|---|---|
| `power` | 0–10 | 单段倍率；写了 `hits` 就必须写 |
| `hits` | 1–10 | 段数；Combo 每段 +1 |
| `piercePct` | 0–1 | 无视目标这个比例的防御 |
| `selfHpCostPct` | 0–1 | 消耗队伍血条的比例（最低保留 1 HP） |
| `statusId` | 状态表 | 附带状态；必须同时写 `turns`（1–10） |
| `statusChance` | 0–1 | **带状态的非硬控技能必写**，硬控不能写。档位见 §5 |
| `executeBonus` + `executeWhen` | 加成 0–3；条件 `vulnerable` / `lowHp`，满足任一即触发 | 必须成对。`lowHp` = 敌人当前血量 / 最大血量 < 40% |
| `debuffScale` | 0–0.3 | **只能用在 `damage`**。目标每有 1 种负面状态伤害 +这个比例，最多计 3 种 |
| `comboThreshold` + `comboDamageBonus` | 门槛 2–9；加成 0–1 | **只能用在 `damage`**。施放时 Combo ≥ 门槛，伤害加成。必须成对 |
| `comboThreshold` + `comboBoostAllies` | 门槛 2–9；人数 1–3 | **只能用在 `buff`**。施放时 Combo ≥ 门槛，多点亮这么多名未行动队友的 BOOST。必须成对 |
| `clearEnemySupports` + `breakTier` | 1–5；1–3 | 拆除敌方支援的个数与强度，必须成对；`breakTier` 不低于支援强度才拆得动 |
| `selfStatus` | `{id,name,amount,turns}` | 目前只有嘲讽技能用 |
| `cleanse` | 布尔 | 只能用在 `heal` |
| `revive` | `"all"` 或 1–4 | 只能用在 `heal` |
| `boostAllies` | 1–3 | 只能用在 `buff` |

### 2.4 侧面支援（`supportDef`）

| 字段 | 范围 | 说明 |
|---|---|---|
| `kind` | `attack` / `armor` / `aura` / `thorns` | 攻击型每回合按发动率攻击；其余常驻 |
| `name`、`element`、`roleText` | | 铭牌与说明 |
| `power`、`hits` | | 攻击型和荆棘型的倍率与段数（支援伤害按 50% 计） |
| `combo` | 整数 0–3 | 攻击型每段给 Combo 加几层，默认 0 |
| `procRate` | 0–1 | 攻击型发动率（默认 60%） |
| `armorTier` | ≥1 | 重装甲档位 |
| `stat`、`amount` | | 光环型提升哪项属性、多少 |
| `tier` | 整数 1–3 | **支援强度**，默认 1；强度 1 界面不显示 |

### 2.5 被动效果字段

被动只在卡上带着该技能、且这张卡没被 Down 时生效。至少写一个，且不能带主动字段。

| 字段 | 范围 | 现有取值 | 说明 |
|---|---|---|---|
| `openingStatus` | | 荆棘 35%，2 回合 | 开局给自己上的状态 |
| `defMul` | 1–2 | 1.1 | 自身 DEF 倍率 |
| `lowHpMul` | 1–2 | 1.25 | 队伍血量低于 30% 时自身 ATK/INT 倍率 |
| `lifesteal` | 0–1 | 20% | 造成伤害的吸血比例 |
| `spellCrit` | 0–50 | 10 | 队伍低血时法术暴击率（百分点） |
| `swift` | 布尔 | | 迅捷：命中 +5，可抢攻 |
| `swiftRate` | 0.25–1 | 初阶 0.5，次阶 0.75，L 版不写（= 1） | 迅捷的抢攻率相对标准的倍数，配合 `swift` 用，下位迅捷靠它打折 |
| `critVsVulnerable` | 0–50 | 15 | 对脆弱目标暴击率（百分点） |
| `regenPct` | 0–1 | 4% | 每回合队伍回复最大生命比例 |
| `controlBonus` | 0–1 | 15% | 硬控与软控成功率 |
| `supportProcBonus` | 0–1 | 15% | 攻击型支援发动率 |
| `apRegenBonus` | 整数 1–3 | 1 | 每回合 AP 恢复；取最大值，不叠层 |
| `healBonus` | 0–1 | 20% | 治疗量 |
| `triggerBonus` | 0–1 | 10% | Boost / 必杀 / 连击概率 |
| `supportShield` | 0–1 | 30% | 敌方拆我方支援时，每个目标免拆概率 |
| `teamDamageReduce` | 0–0.15 | 滞拍格挡 6%、稳拍护盾 4% | 全队受到的伤害减免。只给 Mythic 起的专属被动，上限 15% |

## 3. 槽位与发牌

| 卡型 | 槽位 | 配置 |
|---|---|---|
| C / UC / R / E | 2 | 2/0 约 60%、1/1 约 30%、0/2 约 10%；每张卡各掷各的，发出去就固定 |
| L | 2 | 2/0 约 55%、1/1 约 35%、0/2 约 10% |
| Mythic / Prismatic / 本体卡 | 3 | 3/0、2/1、1/2、0/3；第 3 槽 Mythic 4 命、Prismatic 3 命解锁 |

当前发牌：技能挂在卡实例上，每张卡发出时各掷一次（同名卡互不相同），在**本大职业、且稀有度范围包含这张卡**的技能池里一个一个随机抽，比例见上表（`TWO_SLOT_PLANS`）；Mythic、Prismatic、本体卡有 3 个槽，前两槽按 L 的配比（55/35/10），第 3 槽主动 / 被动各 50%，所以主动数可能是 3、2、1、0。某个职业被动不够时，用主动补满槽位，不留空槽。同一张卡内不重复。

## 4. 定价参考

下面的"现有技能"都是 L 档的基础版本（下位技能见 §7），名字以总表为准。

### 4.1 主动伤害技能：AP 与倍率合计

「倍率合计」= 倍率 × 段数。

| AP | 无附加效果 | 带附加效果 | 现有技能 |
|---|---|---|---|
| 0 | 0.6，单段 | — | 盾击、速射、瞬影刺 |
| 1 | 1.1（多段平刀） | 0.8–1.35 | 乱砍 1.1、疾风箭 1.1、扇舞 1.1；盲抽打断 0.8、断拍震击 0.95、双连盾击 0.96、尖刺盾反 1.0、碎盾 1.0、破魔回响 1.0、藤蔓毒蚀 1.1、霜缚 1.35 |
| 2 | 1.65 | 1.35–1.9 | 圣光裁决 1.65；震地之锤 1.35、影袭 1.35、裂法 1.44、重压破阵 1.45、痛点追斩 1.45、穿甲狙击 1.65、棱光 1.65、雷火崩星 1.9 |
| 3 | 2.3 | 1.95–2.8 | 神威斩 2.3；血祭乱舞 2.0（自损 8%）、异象坍缩 1.95（累积）、强拍星落 2.05（单次）、终幕盾轰 2.35（累积 + 斩杀）、虚弱收割 2.4（累积 + 斩杀）、暗杀奥义 2.8（单次 + 斩杀） |
| 4 | — | 3.9 | 虹彩齐射 3.9（累积 + 燃烧） |

> 无条件倍率合计的基线〔待审〕：0 AP ≈ 0.6；1 AP ≈ 1.1；2 AP ≈ 1.65；3 AP ≈ 2.3；4 AP ≈ 3.9。
> 带附加效果的技能（状态、斩杀、拆除、穿甲、自损）倍率可以低于基线，但**不要高于**。
> 单段技能总倍率要略高于同 AP 的多段技能（约 +5–10%），用伤害换 Combo 速度。
> 0 AP 原则上单段、倍率 ≤ 0.6，价值在铺 Combo。
> 3 AP 以上的高倍率技能靠 `accumulate`（每用一次永久 +1 AP）或 `once`（整场一次）压住，并常带斩杀条件。
> 裂空断头台（2 AP、2.3）是例外中的例外：靠累积和斩杀条件换高倍率，新技能不要照抄。

### 4.4 被动

现有被动大多是单一效果；多效果的（血怒狂躯：增伤 + 吸血；鹰眼：迅捷 + 暴击）按"两个小效果"算。取值见 §2.5。迅捷被动有三个基础版（迅雷、鹰眼、暗影步），每个都有抢攻率打折的下位版。Mythic 起的专属被动有 3 个（滞拍格挡、舞者增幅、稳拍护盾）。

## 5. 状态几率、硬控与拆除强度

### 5.1 状态几率

```
实际几率 = 技能自己的 statusChance × 敌人档位修正（普通 1.0 / 精英 0.8 / BOSS 0.65）
```

| 档位 | statusChance | 状态 |
|---|---|---|
| 弱 | 0.80 | 流血、衰弱、破甲 |
| 中 | 0.65 | 冻结、触电、燃烧、中毒、诅咒 |
| 强 | 0.45 | 沉默、魅惑 |

状态 id 一共 18 种（见 `skill-check.ts` 的 `STATUS_IDS`），除上表外还有恐惧、混乱、眩晕、沉睡、迟缓、禁疗、禁援、荆棘，目前玩家技能里主要用上表这些。新技能附带上表里的状态，就写对应档位的几率；附带别的状态，先和这三档比"这个状态有多狠"再定。下位技能的几率多数与基础版相同，强档状态会再打折（如魅惑，初阶 35%、次阶 40%）。失败时伤害照常，日志写"状态被敌方抵抗"。

### 5.2 硬控

硬控只有两个：粉碎击晕（坦克，3 AP）与深渊眠咒（法师，3 AP）。不写 `statusChance`，走硬控判定：普通 80% / 精英 65% / BOSS 50%，敌人本回合有未被打断的难以打断招式时再 ×0.4（下限 5%）。精英每场最多被硬控 2 次，之后进入警觉。软控（魅惑）走状态几率，强档 45%。

### 5.3 拆除强度与支援强度

| 概念 | 字段 | 规则 |
|---|---|---|
| 支援强度 | `supportDef.tier` | 1–3，默认 1 |
| 拆除强度 | `breakTier` | `breakTier ≥ tier` 才拆得动 |
| 现状 | | 强度 2 的支援：重装甲展开、圣盾、前线号盾、铁棘墙、敌方终曲蓄力；其余强度 1。拆除来源的 `breakTier` 为 1 或 2（重压破阵、失拍噪波是 2，其余是 1） |

支援栏满 7 格时，新支援替换强度最低的非防御支援，且被替换者强度不高于新支援；全满更高强度则不替换。

## 6. 打断

只有盲抽打断带打断：攻击照常结算，之后额外判一次。

```
成功率 = 档位基础率（普通 65% / 精英 55% / BOSS 45%）× 稀有度系数 × （难以打断 ×0.4），限制在 5%–95%
稀有度系数：C 0.90 / UC 0.95 / R 1.00 / E 1.05 / L 1.10 / Mythic 1.15 / Prismatic 1.20；本体卡按最高档 1.20
```

数值在 `battle/config.ts`。失败不掉 Combo，AP 照付。

## 7. 下位技能（C 到 E 品质）

已落地。186 个技能由三部分组成：

| 部分 | 数量 | 发给谁 | 例子 |
|---|---:|---|---|
| 初阶（`_low`） | 43 | C、UC（`maxRarity: UC`） | 轻撞、石锤、铁刺 |
| 次阶（`_mid`） | 49 | R、E（`minRarity: R`、`maxRarity: E`） | 推盾、重锤、锐刺 |
| 基础技能 | 94 | 见下 | 盾击、震地之锤、尖刺盾反 |

基础技能里：

- **L 起**（`minRarity: L`）62 个：常规技能，多数有初阶和次阶两个下位版本，让低品质卡也有同类技能可抽；
- **E 起** 15 个、**Mythic 起** 3 个：只发给高品质卡，没有下位版；
- **全品质通用** 14 个（硬控、单次支援、累积奥义等）：没有下位版。

规则：

| 规则 | 说明 |
|---|---|
| 下位技能是独立技能 | 自己的 id、名字、数值，**不走引擎特殊分支** |
| 怎么削 | AP 不变；倍率、效果量按比例打折，状态持续回合也缩短。**初阶约 ×0.65，次阶约 ×0.85**（如盾击 0.6 → 轻撞 0.4 → 推盾 0.5；震地之锤 1.35 → 石锤 0.9 → 重锤 1.15） |
| 迅捷 | 下位用 `swiftRate`（初阶 0.5、次阶 0.75）打折，不改命中加成 |
| 命名 | 初阶 / 次阶的名字见 `下位技能命名方案 v0.2.md`（2–3 字，一眼看懂） |
| 发牌过滤 | `minRarity` + `maxRarity` 两个字段，发牌按范围过滤（`skillDealtTo`） |
| 复苏结界 | 保持唤醒全部倒下的卡；"只唤醒 1 张"的下位版本到时单独加 |
