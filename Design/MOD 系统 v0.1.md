## 1. 定位

| 项 | 规则 |
|---|---|
| 三个 MOD 满配 | PVE 战力约 **+130%**（进攻型卡约输出 ×2.3，数字是占位，见 §5） |
| 在养成里的位置 | **第二大因素**：小于稀有度（C 到 Prismatic ×3.5），大于等级、命座（满命 +40%） |
| 难度怎么调 | **主线非完美路线按"不带 MOD"调**；完美路线和赛季远征按"带一套不错的 MOD"调 |
| 典型玩家 | 按"典型值"（约顶配的一半，+60% 左右）定敌人强度，不按顶配 |
| 获取节奏（目标） | 一周能刷出一套"能用的"（约 +50%～+70%）；刷到完美要几个月，且靠运气 |
| 性质 | 类似圣遗物，但**不专属**：刷出来一套给谁都能装 |

为什么不做最大：MOD 是乘法，装在 Prismatic 上比装在 C 上绝对值大，稀有度差距还在；最大的战力来源如果是刷出来的东西，卡就成了配角，签名池、市场、金币账都白算。
为什么不做添头：完美路线需要不靠运气、靠时间也能变强的路径；日常体力需要有意义的去处。

## 2. MOD 的构成

- **主词条**：一条，随强化等级上涨。参考 osugacha：7% 到 43.2%，约 6 倍。我们占位：ATK% / INT% 满级 30%。
- **副词条**：**开局就有 4 条**，随机落点强化（每次提升落在这 4 条之一）。
  - 开局副词条**可以看到，但在对应强化之前不生效**（你能看清底子，但效果要强化才启用）。
  - 暴击率与暴击伤害相乘，上限要比 ATK% 卡得更紧。
- **强化**：参考 osugacha 的节奏，每 3 级一次提升，满级 +15（星级沿用设计稿的 6 星，待定）。
- **套装效果**（图里"装备后触发 DEF +12%"这类）：**第一版不做**。
- **重置道具**：把一条副词条重掷成**完全随机**的新词条，真随机，不保底。绑定，不可交易。

## 3. 交易规则

| 项 | 规则 |
|---|---|
| 未强化（+0）的 MOD | **可以交易**，进市场 |
| 强化过的 MOD | **绑定**，不可交易 |
| 强化材料（模组本掉的材料、强化用碎片） | **绑定**，不可交易，也买不到 |
| 重置道具 | 绑定 |
| 买来的 MOD | **可以再卖**，每次成交 **7% 税**（你的理由：底子来回卖，终究会砸在一个人手上） |
| 分解 | 未强化的 MOD 分解只返很少材料（占位约 20%）；强化过的返得多，但它不能交易，所以走不通"金币换材料"的路 |

核心思路：**金币买得到底子，买不到强化**。顶配必须自己花体力刷材料，金币无法直接换成顶配。

关于"好底子"的价值：副词条的落点是随机的，好底子只代表期望值更好，不代表结果更好。所以市场价格主要看主词条和类型，副词条只是小幅加价。想减少挫败感，靠重置道具；它是新的材料出口，要写进材料账。

## 4. 对经济的影响（待算）

- 金币多了"买底子"这个出口，总金币量可能要比现在宽一点。
- 分解返还比例若太高，会变成金币换材料的漏洞，数值要和强化成本一起算。
- 7% 税是金币出口，也是市场摩擦；MOD 市场按"强化前一次性交易"计算。
- 重置道具、强化材料都是体力的新去处，要和 `content/quests.json` 里的体力规则一起核对。
- 市场模拟里加 MOD 档位参数（无、半、满），买卡的"拉力"带上它。
